Deep Dive Notes: Video Streaming Architecture & Transcoding Pipelines

1. Adaptive Bitrate Streaming (ABR): HLS vs MPEG-DASH

  • HLS (HTTP Live Streaming):
  • Developed by Apple, industry standard for iOS, Safari, and widespread web players (video.js, hls.js).
  • Uses .m3u8 playlist files (UTF-8 formatted text) and MPEG-2 TS (.ts) or fragmented MP4 (.fmp4 / .m4s) media chunks.
  • Master playlist references child playlists; child playlists list discrete segments (typically 2 to 6 seconds each).
  • MPEG-DASH (Dynamic Adaptive Streaming over HTTP):
  • International standard (ISO/IEC 23009-1).
  • Uses an XML Media Presentation Description (.mpd) file.
  • Native in Android and Chrome.
  • Client-Side ABR Algorithm:
  • The video player constantly monitors download throughput and playback buffer fullness.
  • If buffer is draining and download speed drops below 2.5Mbps, player requests subsequent chunks from the 480p playlist instead of 1080p, preventing playback stalls and buffering spinners.

2. Ingestion & Transcoding Infrastructure

  • Why Upload Direct to S3?
  • Routing 50GB 4K video files through application API servers exhausts web server RAM, network sockets, and CPU.
  • Using presigned multipart URLs allows the client to stream parts directly to AWS S3 / Azure Blob Storage over HTTPS.
  • DAG Workflow Transcoding:
  • Once upload finishes, S3 triggers an event to AWS SQS / Temporal orchestrator.
  • Distributed GPU workers (FFmpeg / AWS Elemental MediaConvert) download the raw file, split it into chunks, transcode simultaneously across dozens of compute nodes, assemble .m3u8 playlists, and push assets to the origin bucket.

3. LeetCode #46 & #47: Permutations Pruning

  • Permutations I:
  • Each state chooses an unused element: for (int i = 0; i < nums.Length; i++) if (!used[i]).
  • Recurse until current.Count == nums.Length. Total states: $N!$.
  • Permutations II:
  • Why !used[i - 1]?
  • If nums[i] == nums[i - 1] and used[i - 1] is true, nums[i - 1] is an ancestor in the current permutation path, which is valid (e.g., both elements appear in the sequence).
  • If used[i - 1] is false, it means nums[i - 1] was previously chosen and backtracked/completed at the same depth. Picking nums[i] now would explore a duplicate subtree!
  • Therefore, if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) continue; guarantees each unique value is picked exactly once at each permutation position.

Day 38: System Design: Video Streaming System (YouTube/Netflix)

Architectural Overview

A video streaming system (YouTube, Netflix) ingests raw media files, transcodes them into multiple resolutions/bitrates, splits them into short chunk segments, and delivers them globally via Adaptive Bitrate Streaming (ABR) and CDN edge networks.

This module implements key components of video streaming pipelines in .NET 8:

  • Adaptive Bitrate Streaming (ABR) & HLS Manifests:
  • Master Playlist (.m3u8): Encodes multi-variant renditions (1080p @ 5Mbps, 720p @ 2.5Mbps, 480p @ 1.2Mbps, 360p @ 600kbps) with #EXT-X-STREAM-INF.
  • Media Variant Playlist (.m3u8): Specifies target chunk duration (#EXT-X-TARGETDURATION:4) and sequenced .ts segment media URLs.
  • Direct S3 / Blob Multipart Uploads with HMAC Presigned URLs:
  • Bypasses web servers by allowing clients to upload multi-gigabyte video chunks directly to object storage.
  • Generates and verifies HMAC-SHA256 signatures with Unix timestamp expiration.
  • Multipart session tracking ensuring all chunks are uploaded and verified via ETag before transcoding begins.
  • CDN Edge Caching Strategy:
  • Master/Media Playlists: Short TTL (max-age=10, must-revalidate) for rapid adaptation and live stream updates.
  • Video Segments (.ts / .m4s): Immutable assets with maximum TTL (max-age=31536000, immutable), maximizing edge cache hit ratios (>98%).

10 Senior / Staff-Level Interview Questions with In-Depth Answers:
Q1 How does Adaptive Bitrate Streaming (ABR) work in modern video architectures (YouTube, Netflix)?
▼

Answer:

ABR allows video playback to dynamically adapt to varying client network conditions and device capabilities in real time.

  1. During transcoding, the raw video is encoded into multiple bitrates/resolutions (e.g. 1080p, 720p, 480p, 360p) and sliced into short segments (typically 2 to 6 seconds each).
  2. The client video player downloads a Master Playlist (.m3u8 or .mpd) detailing available bitrates.
  3. As the player downloads chunks, it monitors the download throughput and client playback buffer level (e.g. 15 seconds of buffered video).
  4. If network bandwidth degrades (e.g., mobile user entering an elevator), the player automatically requests the next 4-second chunk from a lower bitrate playlist (e.g. 480p instead of 1080p) without interrupting audio/video playback or causing buffering spinners.
Q2 What is the purpose of HLS Master vs Media playlists, and how are they structured?
▼

Answer:

  • Master Playlist (master.m3u8):
  • Serves as the index of all available renditions.
  • Lists #EXT-X-STREAM-INF tags specifying BANDWIDTH, RESOLUTION, CODECS, and audio tracks, each pointing to a Variant Media Playlist URL.
  • Media Playlist (1080p.m3u8):
  • Contains the actual sequence of video chunk segments for a specific resolution.
  • Specifies #EXT-X-TARGETDURATION, sequence numbers, and individual #EXTINF tags with chunk durations followed by the .ts or .m4s segment URLs.
Q3 Why should client video uploads never pass through web application servers, and how do presigned multipart uploads solve this?
▼

Answer:

Routing massive video files (e.g. 10GB–50GB) through web application servers:

  • Exhausts server RAM, saturates network interfaces, and ties up web server worker threads for minutes or hours.
  • If the network drops at 99%, the entire file upload fails.
  • Presigned Multipart Upload Solution:
  1. The client requests an upload session from the API. The API contacts S3/GCS to initiate a multipart upload and returns signed upload URLs for each 5MB–10MB part.
  2. The client streams each part directly to the object storage bucket over HTTPS.
  3. Parts can be uploaded in parallel, and failed parts are retried individually without re-uploading the entire file.
  4. Once all parts are finished, the client notifies the API, which instructs S3 to assemble the completed object.
Q4 How do you design CDN caching strategies for video streaming to achieve >98% cache hit ratio?
▼

Answer:

Segment video assets by mutability:

  1. Video Chunks (.ts, .m4s):
  • Chunks are content-addressed and immutable. Chunk #42 of 1080p will never change.
  • Set HTTP headers: Cache-Control: public, max-age=31536000, immutable.
  • CDN edge nodes cache chunks indefinitely. Once cached at an edge POP, subsequent viewers in that geographic region fetch chunks from local edge NVMe drives rather than traversing back to the origin.
  1. Playlists (.m3u8):
  • Master playlists are cached for short periods (e.g., max-age=60 for VOD; max-age=2 for Live streams).
  • Live stream playlists append new chunks as the stream progresses, so edge caches must revalidate frequently.
Q5 How do you protect premium video content from unauthorized downloads and hotlinking (DRM & Signed URLs)?
▼

Answer:

  1. Signed URLs / Cookies:
  • Issue HMAC-signed tokens with expiration timestamps and client IP restrictions.
  • CDN edge nodes validate the signature before serving playlist or chunk files; unauthorized requests receive HTTP 403 Forbidden without touching origin.
  1. Digital Rights Management (DRM):
  • Encrypt video chunks using AES-128 (Common Encryption cenc).
  • Integrated with platform DRM licensing systems: Apple FairPlay (iOS/Safari), Google Widevine (Android/Chrome), Microsoft PlayReady (Windows/Edge).
  • The player requests an encrypted license key from a DRM Key Server via an authenticated API token. Without the hardware-backed key, the raw .ts files cannot be decoded.
Q6 How does a distributed transcoding pipeline scale to handle thousands of concurrent video uploads?
▼

Answer:

  1. An S3 bucket notification emits an ObjectCreated event to an AWS SQS queue or Apache Kafka topic.
  2. A workflow orchestrator (e.g., Temporal or AWS Step Functions) partitions the video into chunks or keyframe (GOP) boundaries.
  3. GPU worker nodes (auto-scaled on spot instances) claim individual transcoding jobs:
  • Node 1 encodes chunk 1–10 into 1080p H.264/AV1.
  • Node 2 encodes chunk 1–10 into 720p.
  • Node 3 encodes chunk 11–20 into 1080p.
  1. An aggregation worker stitches the manifests, generates thumbnails, and updates the database record to Status = "Published".
Q7 What are the differences between H.264 (AVC), H.265 (HEVC), and AV1 codecs?
▼

Answer:

  • H.264 / AVC: Universal compatibility across 99.9% of devices, browsers, and legacy hardware. Moderate compression efficiency.
  • H.265 / HEVC: ~50% bitrate reduction compared to H.264 at identical visual quality. Standard for 4K/HDR; however, burdened by complex patent licensing pools, limiting native web browser support (predominantly Apple and Smart TVs).
  • AV1: Open-source, royalty-free codec developed by the Alliance for Open Media (Google, Netflix, Apple, Amazon). ~30% more efficient than HEVC, but requires high computational power to encode. Netflix and YouTube encode high-traffic videos in AV1 for massive bandwidth savings.
Q8 In LeetCode #46 (Permutations), what is the time complexity and recursion tree structure?
▼

Answer:

  • For an array of size $N$, there are $N!$ leaf nodes in the recursion tree.
  • At the root level, there are $N$ choices; at depth 1, there are $N - 1$ choices, ..., down to 1 choice at depth $N$.
  • The number of operations to copy each permutation of length $N$ into the output list is $O(N)$.
  • Total Time Complexity: $O(N \times N!)$.
  • Space Complexity: $O(N)$ auxiliary space for the recursion stack and used boolean array.
Q9 In LeetCode #47 (Permutations II), why does `!used[i - 1]` correctly identify duplicate branches, and what would happen if `used[i - 1]` were checked instead?
▼

Answer:

  • In a sorted array with duplicates (e.g., [1, 1, 2]):
  • If nums[i] == nums[i - 1] and !used[i - 1]:
  • It means nums[i - 1] was already chosen at the current recursion level, explored completely, and subsequently unmarked (used[i - 1] = false) during backtracking.
  • Selecting nums[i] now would initiate an identical recursion subtree. Skipping when !used[i - 1] ensures only the first duplicate element is picked as the head of a branch at any level.
  • If one checked used[i - 1] instead, it would prune elements that belong to the same permutation path (ancestor-descendant relationship), preventing valid duplicate occurrences (like [1, 1, 2]) from ever being formed.
Q10 How do you calculate video storage and bandwidth costs for a platform streaming 1 million hours of video daily?
▼

Answer:

  1. Bandwidth Estimation:
  • 1M hours = 3,600,000,000 seconds.
  • Assume average 1080p/720p ABR bitrate of 3 Mbps ($3 \times 10^6 \text{ bits/sec} = 0.375 \text{ MB/sec}$).
  • Daily data transfer: $3.6 \times 10^9 \text{ sec} \times 0.375 \text{ MB} = 1.35 \times 10^9 \text{ MB} = 1.35 \text{ PB/day}$.
  • At CDN negotiated volume rates (\$0.01 per GB), egress cost $\approx \$13,500\text{/day}$.
  1. Storage Estimation:
  • 1 hour of video transcoded across 4 resolutions $\approx 2.5 \text{ GB}$.
  • If 10,000 hours uploaded daily: $10,000 \times 2.5 \text{ GB} = 25 \text{ TB/day}$.
  • Stored on S3 Standard / Infrequent Access with lifecycle tiering to Glacier after 90 days.

namespace Day38.VideoStreaming;

public static class PermutationsSolver
{
    /// <summary>
    /// LeetCode #46: Permutations (Medium).
    /// All elements in nums are distinct.
    /// Time Complexity: O(N * N!), Space Complexity: O(N) stack.
    /// </summary>
    public static IList<IList<int>> Permute(int[] nums)
    {
        var result = new List<IList<int>>();
        if (nums == null || nums.Length == 0) return result;

        var used = new bool[nums.Length];
        var current = new List<int>(nums.Length);
        BacktrackPermute(nums, used, current, result);
        return result;
    }

    private static void BacktrackPermute(int[] nums, bool[] used, List<int> current, List<IList<int>> result)
    {
        if (current.Count == nums.Length)
        {
            result.Add(new List<int>(current));
            return;
        }

        for (int i = 0; i < nums.Length; i++)
        {
            if (used[i]) continue;

            used[i] = true;
            current.Add(nums[i]);
            BacktrackPermute(nums, used, current, result);
            current.RemoveAt(current.Count - 1);
            used[i] = false;
        }
    }

    /// <summary>
    /// LeetCode #47: Permutations II (Medium).
    /// Elements in nums may contain duplicates. Output must contain unique permutations.
    /// Time Complexity: O(N * N!), Space Complexity: O(N).
    /// </summary>
    public static IList<IList<int>> PermuteUnique(int[] nums)
    {
        var result = new List<IList<int>>();
        if (nums == null || nums.Length == 0) return result;

        Array.Sort(nums);
        var used = new bool[nums.Length];
        var current = new List<int>(nums.Length);
        BacktrackPermuteUnique(nums, used, current, result);
        return result;
    }

    private static void BacktrackPermuteUnique(int[] nums, bool[] used, List<int> current, List<IList<int>> result)
    {
        if (current.Count == nums.Length)
        {
            result.Add(new List<int>(current));
            return;
        }

        for (int i = 0; i < nums.Length; i++)
        {
            if (used[i]) continue;

            // If current element is duplicate of previous element, and previous duplicate
            // was NOT used in current recursion branch, skip to avoid duplicate permutations.
            if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1])
            {
                continue;
            }

            used[i] = true;
            current.Add(nums[i]);
            BacktrackPermuteUnique(nums, used, current, result);
            current.RemoveAt(current.Count - 1);
            used[i] = false;
        }
    }
}

using System.Security.Cryptography;
using System.Text;

namespace Day38.VideoStreaming;

public enum VideoResolution
{
    Res360p,
    Res480p,
    Res720p,
    Res1080p
}

public record VideoRendition(VideoResolution Resolution, int Width, int Height, int BitrateBps, string PlaylistName);

public record VideoSegment(int Index, double DurationSeconds, string Uri);

public class HlsPlaylistGenerator
{
    public static readonly IReadOnlyList<VideoRendition> StandardRenditions = new List<VideoRendition>
    {
        new(VideoResolution.Res1080p, 1920, 1080, 5000000, "1080p.m3u8"),
        new(VideoResolution.Res720p, 1280, 720, 2500000, "720p.m3u8"),
        new(VideoResolution.Res480p, 854, 480, 1200000, "480p.m3u8"),
        new(VideoResolution.Res360p, 640, 360, 600000, "360p.m3u8")
    };

    /// <summary>
    /// Generates HLS Master Playlist referencing multiple ABR bitrate streams.
    /// </summary>
    public static string GenerateMasterPlaylist(string baseUrl, IEnumerable<VideoRendition>? renditions = null)
    {
        renditions ??= StandardRenditions;
        var sb = new StringBuilder();
        sb.AppendLine("#EXTM3U");
        sb.AppendLine("#EXT-X-VERSION:4");

        foreach (var r in renditions.OrderByDescending(x => x.BitrateBps))
        {
            sb.AppendLine($"#EXT-X-STREAM-INF:BANDWIDTH={r.BitrateBps},RESOLUTION={r.Width}x{r.Height},NAME=\"{r.Height}p\"");
            sb.AppendLine($"{baseUrl.TrimEnd('/')}/{r.PlaylistName}");
        }

        return sb.ToString();
    }

    /// <summary>
    /// Generates HLS Media Variant Playlist (.m3u8) referencing .ts or .m4s video chunks.
    /// </summary>
    public static string GenerateMediaPlaylist(double targetDuration, IEnumerable<VideoSegment> segments)
    {
        var sb = new StringBuilder();
        sb.AppendLine("#EXTM3U");
        sb.AppendLine("#EXT-X-VERSION:4");
        sb.AppendLine($"#EXT-X-TARGETDURATION:{Math.Ceiling(targetDuration)}");
        sb.AppendLine("#EXT-X-MEDIA-SEQUENCE:0");
        sb.AppendLine("#EXT-X-PLAYLIST-TYPE:VOD");

        foreach (var seg in segments.OrderBy(s => s.Index))
        {
            sb.AppendLine($"#EXTINF:{seg.DurationSeconds:0.000},");
            sb.AppendLine(seg.Uri);
        }

        sb.AppendLine("#EXT-X-ENDLIST");
        return sb.ToString();
    }
}

public record MultipartUploadSession(
    string UploadId,
    string VideoId,
    int TotalParts,
    long PartSizeBytes,
    Dictionary<int, string> CompletedParts
);

public class PresignedUploadManager
{
    private readonly byte[] _hmacSecret;
    private readonly Dictionary<string, MultipartUploadSession> _activeSessions = new();
    private readonly object _lock = new();

    public PresignedUploadManager(string secretKey)
    {
        _hmacSecret = Encoding.UTF8.GetBytes(secretKey);
    }

    public MultipartUploadSession InitiateUpload(string videoId, long totalFileBytes, long partSizeBytes = 5 * 1024 * 1024)
    {
        int totalParts = (int)Math.Ceiling((double)totalFileBytes / partSizeBytes);
        var session = new MultipartUploadSession(
            UploadId: Guid.NewGuid().ToString("N"),
            VideoId: videoId,
            TotalParts: totalParts,
            PartSizeBytes: partSizeBytes,
            CompletedParts: new Dictionary<int, string>()
        );

        lock (_lock)
        {
            _activeSessions[session.UploadId] = session;
        }

        return session;
    }

    public string GeneratePresignedPartUrl(string uploadId, int partNumber, TimeSpan validDuration)
    {
        long expiry = DateTimeOffset.UtcNow.Add(validDuration).ToUnixTimeSeconds();
        string payload = $"{uploadId}:{partNumber}:{expiry}";
        using var hmac = new HMACSHA256(_hmacSecret);
        var sigBytes = hmac.ComputeHash(Encoding.UTF8.GetBytes(payload));
        string signature = Convert.ToHexString(sigBytes).ToLowerInvariant();

        return $"/storage/upload?uploadId={uploadId}&part={partNumber}&exp={expiry}&sig={signature}";
    }

    public bool VerifyAndCompletePart(string uploadId, int partNumber, long expiry, string signature, string partEtag)
    {
        if (DateTimeOffset.UtcNow.ToUnixTimeSeconds() > expiry)
        {
            return false; // Expired
        }

        string payload = $"{uploadId}:{partNumber}:{expiry}";
        using var hmac = new HMACSHA256(_hmacSecret);
        var expectedSig = Convert.ToHexString(hmac.ComputeHash(Encoding.UTF8.GetBytes(payload))).ToLowerInvariant();

        if (expectedSig != signature)
        {
            return false; // Tampered signature
        }

        lock (_lock)
        {
            if (!_activeSessions.TryGetValue(uploadId, out var session))
            {
                return false;
            }

            session.CompletedParts[partNumber] = partEtag;
            return true;
        }
    }

    public bool IsUploadComplete(string uploadId)
    {
        lock (_lock)
        {
            if (_activeSessions.TryGetValue(uploadId, out var session))
            {
                return session.CompletedParts.Count == session.TotalParts;
            }
            return false;
        }
    }
}

public record CdnCacheHeaders(string CacheControl, int TtlSeconds);

public static class CdnEdgeRules
{
    public static CdnCacheHeaders GetCachePolicy(string resourcePath)
    {
        if (resourcePath.EndsWith(".m3u8"))
        {
            // Master/Media playlists are dynamic and short-lived
            return new CdnCacheHeaders("public, max-age=10, must-revalidate", 10);
        }
        else if (resourcePath.EndsWith(".ts") || resourcePath.EndsWith(".m4s"))
        {
            // Immutable video chunk segments - cache aggressively for 1 year
            return new CdnCacheHeaders("public, max-age=31536000, immutable", 31536000);
        }

        return new CdnCacheHeaders("public, max-age=3600", 3600);
    }
}

📝 Part 1: Deep-Dive Architectural & Engineering Notes

Deep Dive Notes: Video Streaming Architecture & Transcoding Pipelines

1. Adaptive Bitrate Streaming (ABR): HLS vs MPEG-DASH

  • HLS (HTTP Live Streaming):
  • Developed by Apple, industry standard for iOS, Safari, and widespread web players (video.js, hls.js).
  • Uses .m3u8 playlist files (UTF-8 formatted text) and MPEG-2 TS (.ts) or fragmented MP4 (.fmp4 / .m4s) media chunks.
  • Master playlist references child playlists; child playlists list discrete segments (typically 2 to 6 seconds each).
  • MPEG-DASH (Dynamic Adaptive Streaming over HTTP):
  • International standard (ISO/IEC 23009-1).
  • Uses an XML Media Presentation Description (.mpd) file.
  • Native in Android and Chrome.
  • Client-Side ABR Algorithm:
  • The video player constantly monitors download throughput and playback buffer fullness.
  • If buffer is draining and download speed drops below 2.5Mbps, player requests subsequent chunks from the 480p playlist instead of 1080p, preventing playback stalls and buffering spinners.

2. Ingestion & Transcoding Infrastructure

  • Why Upload Direct to S3?
  • Routing 50GB 4K video files through application API servers exhausts web server RAM, network sockets, and CPU.
  • Using presigned multipart URLs allows the client to stream parts directly to AWS S3 / Azure Blob Storage over HTTPS.
  • DAG Workflow Transcoding:
  • Once upload finishes, S3 triggers an event to AWS SQS / Temporal orchestrator.
  • Distributed GPU workers (FFmpeg / AWS Elemental MediaConvert) download the raw file, split it into chunks, transcode simultaneously across dozens of compute nodes, assemble .m3u8 playlists, and push assets to the origin bucket.

3. LeetCode #46 & #47: Permutations Pruning

  • Permutations I:
  • Each state chooses an unused element: for (int i = 0; i < nums.Length; i++) if (!used[i]).
  • Recurse until current.Count == nums.Length. Total states: $N!$.
  • Permutations II:
  • Why !used[i - 1]?
  • If nums[i] == nums[i - 1] and used[i - 1] is true, nums[i - 1] is an ancestor in the current permutation path, which is valid (e.g., both elements appear in the sequence).
  • If used[i - 1] is false, it means nums[i - 1] was previously chosen and backtracked/completed at the same depth. Picking nums[i] now would explore a duplicate subtree!
  • Therefore, if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) continue; guarantees each unique value is picked exactly once at each permutation position.

💡 Part 3: Senior & Staff-Level Interview Scenarios (10 Questions)

Q1 How does Adaptive Bitrate Streaming (ABR) work in modern video architectures (YouTube, Netflix)?
▼

Answer:

ABR allows video playback to dynamically adapt to varying client network conditions and device capabilities in real time.

  1. During transcoding, the raw video is encoded into multiple bitrates/resolutions (e.g. 1080p, 720p, 480p, 360p) and sliced into short segments (typically 2 to 6 seconds each).
  2. The client video player downloads a Master Playlist (.m3u8 or .mpd) detailing available bitrates.
  3. As the player downloads chunks, it monitors the download throughput and client playback buffer level (e.g. 15 seconds of buffered video).
  4. If network bandwidth degrades (e.g., mobile user entering an elevator), the player automatically requests the next 4-second chunk from a lower bitrate playlist (e.g. 480p instead of 1080p) without interrupting audio/video playback or causing buffering spinners.
Q2 What is the purpose of HLS Master vs Media playlists, and how are they structured?
▼

Answer:

  • Master Playlist (master.m3u8):
  • Serves as the index of all available renditions.
  • Lists #EXT-X-STREAM-INF tags specifying BANDWIDTH, RESOLUTION, CODECS, and audio tracks, each pointing to a Variant Media Playlist URL.
  • Media Playlist (1080p.m3u8):
  • Contains the actual sequence of video chunk segments for a specific resolution.
  • Specifies #EXT-X-TARGETDURATION, sequence numbers, and individual #EXTINF tags with chunk durations followed by the .ts or .m4s segment URLs.
Q3 Why should client video uploads never pass through web application servers, and how do presigned multipart uploads solve this?
▼

Answer:

Routing massive video files (e.g. 10GB–50GB) through web application servers:

  • Exhausts server RAM, saturates network interfaces, and ties up web server worker threads for minutes or hours.
  • If the network drops at 99%, the entire file upload fails.
  • Presigned Multipart Upload Solution:
  1. The client requests an upload session from the API. The API contacts S3/GCS to initiate a multipart upload and returns signed upload URLs for each 5MB–10MB part.
  2. The client streams each part directly to the object storage bucket over HTTPS.
  3. Parts can be uploaded in parallel, and failed parts are retried individually without re-uploading the entire file.
  4. Once all parts are finished, the client notifies the API, which instructs S3 to assemble the completed object.
Q4 How do you design CDN caching strategies for video streaming to achieve >98% cache hit ratio?
▼

Answer:

Segment video assets by mutability:

  1. Video Chunks (.ts, .m4s):
  • Chunks are content-addressed and immutable. Chunk #42 of 1080p will never change.
  • Set HTTP headers: Cache-Control: public, max-age=31536000, immutable.
  • CDN edge nodes cache chunks indefinitely. Once cached at an edge POP, subsequent viewers in that geographic region fetch chunks from local edge NVMe drives rather than traversing back to the origin.
  1. Playlists (.m3u8):
  • Master playlists are cached for short periods (e.g., max-age=60 for VOD; max-age=2 for Live streams).
  • Live stream playlists append new chunks as the stream progresses, so edge caches must revalidate frequently.
Q5 How do you protect premium video content from unauthorized downloads and hotlinking (DRM & Signed URLs)?
▼

Answer:

  1. Signed URLs / Cookies:
  • Issue HMAC-signed tokens with expiration timestamps and client IP restrictions.
  • CDN edge nodes validate the signature before serving playlist or chunk files; unauthorized requests receive HTTP 403 Forbidden without touching origin.
  1. Digital Rights Management (DRM):
  • Encrypt video chunks using AES-128 (Common Encryption cenc).
  • Integrated with platform DRM licensing systems: Apple FairPlay (iOS/Safari), Google Widevine (Android/Chrome), Microsoft PlayReady (Windows/Edge).
  • The player requests an encrypted license key from a DRM Key Server via an authenticated API token. Without the hardware-backed key, the raw .ts files cannot be decoded.
Q6 How does a distributed transcoding pipeline scale to handle thousands of concurrent video uploads?
▼

Answer:

  1. An S3 bucket notification emits an ObjectCreated event to an AWS SQS queue or Apache Kafka topic.
  2. A workflow orchestrator (e.g., Temporal or AWS Step Functions) partitions the video into chunks or keyframe (GOP) boundaries.
  3. GPU worker nodes (auto-scaled on spot instances) claim individual transcoding jobs:
  • Node 1 encodes chunk 1–10 into 1080p H.264/AV1.
  • Node 2 encodes chunk 1–10 into 720p.
  • Node 3 encodes chunk 11–20 into 1080p.
  1. An aggregation worker stitches the manifests, generates thumbnails, and updates the database record to Status = "Published".
Q7 What are the differences between H.264 (AVC), H.265 (HEVC), and AV1 codecs?
▼

Answer:

  • H.264 / AVC: Universal compatibility across 99.9% of devices, browsers, and legacy hardware. Moderate compression efficiency.
  • H.265 / HEVC: ~50% bitrate reduction compared to H.264 at identical visual quality. Standard for 4K/HDR; however, burdened by complex patent licensing pools, limiting native web browser support (predominantly Apple and Smart TVs).
  • AV1: Open-source, royalty-free codec developed by the Alliance for Open Media (Google, Netflix, Apple, Amazon). ~30% more efficient than HEVC, but requires high computational power to encode. Netflix and YouTube encode high-traffic videos in AV1 for massive bandwidth savings.
Q8 In LeetCode #46 (Permutations), what is the time complexity and recursion tree structure?
▼

Answer:

  • For an array of size $N$, there are $N!$ leaf nodes in the recursion tree.
  • At the root level, there are $N$ choices; at depth 1, there are $N - 1$ choices, ..., down to 1 choice at depth $N$.
  • The number of operations to copy each permutation of length $N$ into the output list is $O(N)$.
  • Total Time Complexity: $O(N \times N!)$.
  • Space Complexity: $O(N)$ auxiliary space for the recursion stack and used boolean array.
Q9 In LeetCode #47 (Permutations II), why does `!used[i - 1]` correctly identify duplicate branches, and what would happen if `used[i - 1]` were checked instead?
▼

Answer:

  • In a sorted array with duplicates (e.g., [1, 1, 2]):
  • If nums[i] == nums[i - 1] and !used[i - 1]:
  • It means nums[i - 1] was already chosen at the current recursion level, explored completely, and subsequently unmarked (used[i - 1] = false) during backtracking.
  • Selecting nums[i] now would initiate an identical recursion subtree. Skipping when !used[i - 1] ensures only the first duplicate element is picked as the head of a branch at any level.
  • If one checked used[i - 1] instead, it would prune elements that belong to the same permutation path (ancestor-descendant relationship), preventing valid duplicate occurrences (like [1, 1, 2]) from ever being formed.

namespace Day38.VideoStreaming;

public static class PermutationsSolver
{
    /// <summary>
    /// LeetCode #46: Permutations (Medium).
    /// All elements in nums are distinct.
    /// Time Complexity: O(N * N!), Space Complexity: O(N) stack.
    /// </summary>
    public static IList<IList<int>> Permute(int[] nums)
    {
        var result = new List<IList<int>>();
        if (nums == null || nums.Length == 0) return result;

        var used = new bool[nums.Length];
        var current = new List<int>(nums.Length);
        BacktrackPermute(nums, used, current, result);
        return result;
    }

    private static void BacktrackPermute(int[] nums, bool[] used, List<int> current, List<IList<int>> result)
    {
        if (current.Count == nums.Length)
        {
            result.Add(new List<int>(current));
            return;
        }

        for (int i = 0; i < nums.Length; i++)
        {
            if (used[i]) continue;

            used[i] = true;
            current.Add(nums[i]);
            BacktrackPermute(nums, used, current, result);
            current.RemoveAt(current.Count - 1);
            used[i] = false;
        }
    }

    /// <summary>
    /// LeetCode #47: Permutations II (Medium).
    /// Elements in nums may contain duplicates. Output must contain unique permutations.
    /// Time Complexity: O(N * N!), Space Complexity: O(N).
    /// </summary>
    public static IList<IList<int>> PermuteUnique(int[] nums)
    {
        var result = new List<IList<int>>();
        if (nums == null || nums.Length == 0) return result;

        Array.Sort(nums);
        var used = new bool[nums.Length];
        var current = new List<int>(nums.Length);
        BacktrackPermuteUnique(nums, used, current, result);
        return result;
    }

    private static void BacktrackPermuteUnique(int[] nums, bool[] used, List<int> current, List<IList<int>> result)
    {
        if (current.Count == nums.Length)
        {
            result.Add(new List<int>(current));
            return;
        }

        for (int i = 0; i < nums.Length; i++)
        {
            if (used[i]) continue;

            // If current element is duplicate of previous element, and previous duplicate
            // was NOT used in current recursion branch, skip to avoid duplicate permutations.
            if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1])
            {
                continue;
            }

            used[i] = true;
            current.Add(nums[i]);
            BacktrackPermuteUnique(nums, used, current, result);
            current.RemoveAt(current.Count - 1);
            used[i] = false;
        }
    }
}

namespace Day38.VideoStreaming;

public enum VideoResolution

    Res360p,
    Res480p,

    Res1080p

public record VideoRendition(VideoResolution Resolution, int Width, int Height, int BitrateBps, string PlaylistName);

public record VideoSegment(int Index, double DurationSeconds, string Uri);

public class HlsPlaylistGenerator
{
    public static readonly IReadOnlyList<VideoRendition> StandardRenditions = new List<VideoRendition>
    {
        new(VideoResolution.Res1080p, 1920, 1080, 5000000, "1080p.m3u8"),
        new(VideoResolution.Res720p, 1280, 720, 2500000, "720p.m3u8"),
        new(VideoResolution.Res480p, 854, 480, 1200000, "480p.m3u8"),
        new(VideoResolution.Res360p, 640, 360, 600000, "360p.m3u8")
    };

    /// <summary>
    /// Generates HLS Master Playlist referencing multiple ABR bitrate streams.
    /// </summary>
    public static string GenerateMasterPlaylist(string baseUrl, IEnumerable<VideoRendition>? renditions = null)
    {
        renditions ??= StandardRenditions;
        var sb = new StringBuilder();
        sb.AppendLine("#EXTM3U");
        sb.AppendLine("#EXT-X-VERSION:4");

        foreach (var r in renditions.OrderByDescending(x => x.BitrateBps))
        {
            sb.AppendLine($"#EXT-X-STREAM-INF:BANDWIDTH={r.BitrateBps},RESOLUTION={r.Width}x{r.Height},NAME=\"{r.Height}p\"");
            sb.AppendLine($"{baseUrl.TrimEnd('/')}/{r.PlaylistName}");
        }

        return sb.ToString();
    }

    /// <summary>
    /// Generates HLS Media Variant Playlist (.m3u8) referencing .ts or .m4s video chunks.
    /// </summary>
    public static string GenerateMediaPlaylist(double targetDuration, IEnumerable<VideoSegment> segments)
    {
        var sb = new StringBuilder();
        sb.AppendLine("#EXTM3U");
        sb.AppendLine("#EXT-X-VERSION:4");
        sb.AppendLine($"#EXT-X-TARGETDURATION:{Math.Ceiling(targetDuration)}");
        sb.AppendLine("#EXT-X-MEDIA-SEQUENCE:0");
        sb.AppendLine("#EXT-X-PLAYLIST-TYPE:VOD");

        foreach (var seg in segments.OrderBy(s => s.Index))
        {
            sb.AppendLine($"#EXTINF:{seg.DurationSeconds:0.000},");
            sb.AppendLine(seg.Uri);
        }

        sb.AppendLine("#EXT-X-ENDLIST");
        return sb.ToString();
    }
}

public record MultipartUploadSession(
    string UploadId,
    string VideoId,
    int TotalParts,
    long PartSizeBytes,
    Dictionary<int, string> CompletedParts
);

public class PresignedUploadManager
{
    private readonly byte[] _hmacSecret;
    private readonly Dictionary<string, MultipartUploadSession> _activeSessions = new();
    private readonly object _lock = new();

    public PresignedUploadManager(string secretKey)
    {
        _hmacSecret = Encoding.UTF8.GetBytes(secretKey);
    }

    public MultipartUploadSession InitiateUpload(string videoId, long totalFileBytes, long partSizeBytes = 5 * 1024 * 1024)
    {
        int totalParts = (int)Math.Ceiling((double)totalFileBytes / partSizeBytes);
        var session = new MultipartUploadSession(
            UploadId: Guid.NewGuid().ToString("N"),
            VideoId: videoId,
            TotalParts: totalParts,
            PartSizeBytes: partSizeBytes,
            CompletedParts: new Dictionary<int, string>()
        );

        lock (_lock)
        {
            _activeSessions[session.UploadId] = session;
        }

        return session;
    }

    public string GeneratePresignedPartUrl(string uploadId, int partNumber, TimeSpan validDuration)
    {
        long expiry = DateTimeOffset.UtcNow.Add(validDuration).ToUnixTimeSeconds();
        string payload = $"{uploadId}:{partNumber}:{expiry}";
        using var hmac = new HMACSHA256(_hmacSecret);
        var sigBytes = hmac.ComputeHash(Encoding.UTF8.GetBytes(payload));
        string signature = Convert.ToHexString(sigBytes).ToLowerInvariant();

        return $"/storage/upload?uploadId={uploadId}&part={partNumber}&exp={expiry}&sig={signature}";
    }

    public bool VerifyAndCompletePart(string uploadId, int partNumber, long expiry, string signature, string partEtag)
    {
        if (DateTimeOffset.UtcNow.ToUnixTimeSeconds() > expiry)
        {
            return false; // Expired
        }

        string payload = $"{uploadId}:{partNumber}:{expiry}";
        using var hmac = new HMACSHA256(_hmacSecret);
        var expectedSig = Convert.ToHexString(hmac.ComputeHash(Encoding.UTF8.GetBytes(payload))).ToLowerInvariant();

        if (expectedSig != signature)
        {
            return false; // Tampered signature
        }

        lock (_lock)
        {
            if (!_activeSessions.TryGetValue(uploadId, out var session))
            {
                return false;
            }

            session.CompletedParts[partNumber] = partEtag;
            return true;
        }
    }

    public bool IsUploadComplete(string uploadId)
    {
        lock (_lock)
        {
            if (_activeSessions.TryGetValue(uploadId, out var session))
            {
                return session.CompletedParts.Count == session.TotalParts;
            }
            return false;
        }
    }
}

public record CdnCacheHeaders(string CacheControl, int TtlSeconds);

public static class CdnEdgeRules
{
    public static CdnCacheHeaders GetCachePolicy(string resourcePath)
    {
        if (resourcePath.EndsWith(".m3u8"))
        {
            // Master/Media playlists are dynamic and short-lived
            return new CdnCacheHeaders("public, max-age=10, must-revalidate", 10);
        }
        else if (resourcePath.EndsWith(".ts") || resourcePath.EndsWith(".m4s"))
        {
            // Immutable video chunk segments - cache aggressively for 1 year
            return new CdnCacheHeaders("public, max-age=31536000, immutable", 31536000);
        }

        return new CdnCacheHeaders("public, max-age=3600", 3600);
    }
}

    public void PermutationsUnique_WithDuplicates_ReturnsUniqueCount()
    {

    }
