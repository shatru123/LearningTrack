Deep Dive Notes: ConfigMaps, Secrets & Ingress Controllers

1. Atomic Symlink Volume Swapping

When a ConfigMap is mounted as a volume in a Pod:

/etc/config/appsettings.json -> /etc/config/..data/appsettings.json
/etc/config/..data -> /etc/config/..2026_10_23_14_00_00.123456789 (symlink)

When kubectl apply updates the ConfigMap, the kubelet creates a new timestamped directory and updates the ..data symlink atomically using the rename() system call. This prevents race conditions where an application reads half-written config files.

2. Ingress Controller Architecture

Ingress resources are merely metadata declarations. The Ingress Controller is an application (running an NGINX, Envoy, or Traefik pod) watching the kube-apiserver for Ingress events. Upon changes, it dynamically regenerates the reverse proxy configuration (nginx.conf) and issues a reload without dropping active TCP connections.

Day 44: Kubernetes ConfigMaps, Secrets & Ingress

Overview

Day 44 covers decoupled application configuration and external routing architecture in Kubernetes using ConfigMaps, Secrets, and Ingress Controllers (NGINX / Traefik).

Architecture Highlights

  • ConfigMaps: Inject non-sensitive environment variables, JSON configs, and feature toggles into Pods without rebuilding container images.
  • Secrets: Base64 encoded (or SealedSecrets / Vault CSI) sensitive database connection strings, JWT signing keys, and TLS certificates.
  • Hot-Reloading with ..data Symlink: Kubernetes mounts ConfigMaps/Secrets as volume files using atomic directory symlink swapping, enabling .NET IOptionsSnapshot<T> reloading without container restarts.
  • Ingress Controller (NGINX): Layer 7 HTTP/HTTPS reverse proxy handling TLS termination, virtual host dispatching, and path-based routing (/orders -> order-service:80, /inventory -> inventory-service:80).

DSA Problems

  • LeetCode #647 (Palindromic Substrings): Center expansion counting odd and even palindromes in $\mathcal{O}(N^2)$ time and $\mathcal{O}(1)$ space.
  • LeetCode #91 (Decode Ways): 1D Dynamic Programming tracking single-digit ($1-9$) and two-digit ($10-26$) transitions with zero validation in $\mathcal{O}(N)$ time and $\mathcal{O}(1)$ space.

10 Senior / Staff-Level Interview Questions with In-Depth Answers:
Q1 How do ConfigMaps mounted as environment variables differ from ConfigMaps mounted as volume files?
▼

Answer:

  • Environment Variables: Injected at container startup. If the ConfigMap is modified in Kubernetes, the container's environment variables do not update until the Pod is restarted (kubectl rollout restart).
  • Volume Mounts: Mounted into the filesystem via atomic symlink swap (..data). Kubelet synchronizes changes automatically (typically within 60–90 seconds). Applications using file watchers (such as .NET reloadOnChange: true in ConfigurationBuilder) can hot-reload changes without container restarts.
Q2 Why are standard Kubernetes Secrets not secure by default, and how should they be protected in production?
▼

Answer:

Standard Kubernetes Secrets are merely Base64-encoded strings stored in plaintext within etcd. Anyone with read RBAC permissions or access to etcd disk backups can view them.

In production:

  1. Enable etcd Encryption at Rest via KMS (AWS KMS, Azure Key Vault, HashiCorp Vault).
  2. Use HashiCorp Vault Secrets Store CSI Driver or External Secrets Operator to synchronize secrets directly into Pod memory without persisting plaintext in etcd.
  3. Use Bitnami Sealed Secrets to safely commit asymmetrically encrypted secrets to Git.
Q3 How does NGINX Ingress handle TLS termination and certificate management?
▼

Answer:

  1. The TLS certificate and private key are stored in a Kubernetes Secret of type kubernetes.io/tls with tls.crt and tls.key.
  2. The Ingress resource references this secret in spec.tls[*].secretName.
  3. The Ingress Controller loads the certificate, terminates the incoming client TLS handshake, decrypts HTTP requests, and forwards plaintext HTTP traffic (or re-encrypted internal mTLS) to backend ClusterIP pods.
  4. Tools like cert-manager automate ACME (Let's Encrypt) challenge solving and certificate renewal.
Q4 Explain the dynamic programming state transition for LeetCode #91 Decode Ways.
▼

Answer:

Let $dp[i]$ be the number of ways to decode string prefix of length $i$:

  • Single digit ($1 \le s[i-1] \le 9$): $dp[i] += dp[i-1]$.
  • Two digits ($10 \le s[i-2..i-1] \le 26$): $dp[i] += dp[i-2]$.
  • Edge cases: If $s[0] == '0'$, return 0 immediately. If an invalid two-digit sequence occurs (e.g. "30" or "00"), no transitions apply and result becomes 0.

Space complexity is optimized to $\mathcal{O}(1)$ by retaining only prev1 ($dp[i-1]$) and prev2 ($dp[i-2]$).

Q5 What is the purpose of the `nginx.ingress.kubernetes.io/rewrite-target` annotation?
▼

Answer:

Microservices frequently expect routes at root (/checkout), while the external API Gateway or Ingress exposes them namespaced under a prefix (/orders/checkout).

The rewrite-target: /$2 annotation together with path regex /orders(/|$)(.*) strips the /orders prefix before proxying the request to the backend service.

Q6 How do you configure ASP.NET Core to read mounted Kubernetes ConfigMaps and Secrets?
▼

Answer:

Use AddKeyPerFile:

builder.Configuration
    .AddKeyPerFile(directoryPath: "/etc/config", optional: true, reloadOnChange: true)
    .AddKeyPerFile(directoryPath: "/etc/secrets", optional: true, reloadOnChange: false);

Each file inside the directory becomes a configuration key whose value is the file's content.

Q7 What is the difference between Ingress and Gateway API in modern Kubernetes?
▼

Answer:

  • Ingress: Mature Layer 7 routing specification (networking.k8s.io/v1), but limited in advanced routing (canary releases, header-based routing, weighted splitting) which required vendor-specific annotations.
  • Gateway API: The modern successor (gateway.networking.k8s.io), providing role-oriented interfaces (GatewayClass, Gateway, HTTPRoute) with first-class support for multi-tenancy, cross-namespace routing, canary traffic splitting, and Layer 4/7 protocols.
Q8 What happens if an Ingress resource specifies a host that does not match the client request's HTTP Host header or SNI?
▼

Answer:

The Ingress Controller either routes the request to the default-backend (which typically returns HTTP 404 Not Found) or rejects the connection if strict host routing is configured.

Q9 How can you protect sensitive configuration values from appearing in container crash dumps or logs?
▼

Answer:

  1. Mount secrets as files in memory (tmpfs volume) instead of environment variables, since environment variables are printed by /proc/[pid]/environ and logging tools.
  2. Configure structured logging redaction in .NET using Microsoft's Microsoft.Extensions.Compliance.Redaction to mask PII and credentials.
  3. Configure automountServiceAccountToken: false on Pods that do not require Kubernetes API access.
Q10 How does LeetCode #647 Palindromic Substrings differ from LeetCode #5 Longest Palindromic Substring?
▼

Answer:

While LC #5 seeks the maximum length palindrome, LC #647 counts every valid palindromic substring across the entire string. Both can be solved in $\mathcal{O}(N^2)$ time using the center-expansion technique, where every step outward in expansion increments the global palindrome counter by 1.

using System;
using System.Collections.Generic;
using System.Text;
using System.Text.RegularExpressions;

namespace Day44.KubernetesConfigIngress;

public record IngressRoute(
    string Host,
    string PathPrefix,
    string TargetService,
    int TargetPort,
    bool RewriteEnabled
);

public class KubernetesConfigAndIngressEngine
{
    private readonly Dictionary<string, string> _configurationStore = new();
    private readonly List<IngressRoute> _routes = new();
    private bool _tlsTerminated = false;

    public void LoadConfigMap(Dictionary<string, string> data)
    {
        foreach (var (k, v) in data)
        {
            _configurationStore[k] = v;
        }
    }

    public void LoadSecret(Dictionary<string, string> base64Data)
    {
        foreach (var (k, base64Val) in base64Data)
        {
            var decodedBytes = Convert.FromBase64String(base64Val);
            _configurationStore[k] = Encoding.UTF8.GetString(decodedBytes);
        }
    }

    public string? GetConfigValue(string key) => _configurationStore.GetValueOrDefault(key);

    public void RegisterIngressRoute(IngressRoute route)
    {
        _routes.Add(route);
    }

    public (bool Matched, string? TargetService, string? ForwardedPath) RouteRequest(string host, string requestPath, bool isHttps)
    {
        foreach (var r in _routes)
        {
            if (string.Equals(r.Host, host, StringComparison.OrdinalIgnoreCase))
            {
                if (requestPath.StartsWith(r.PathPrefix, StringComparison.OrdinalIgnoreCase))
                {
                    string forwarded = requestPath;
                    if (r.RewriteEnabled)
                    {
                        forwarded = requestPath.Substring(r.PathPrefix.Length);
                        if (!forwarded.StartsWith("/")) forwarded = "/" + forwarded;
                    }
                    return (true, $"{r.TargetService}:{r.TargetPort}", forwarded);
                }
            }
        }
        return (false, null, null);
    }

    public bool SimulateHotReload(string symlinkDataDir, Dictionary<string, string> updatedData)
    {
        // Simulates Kubelet updating the ..data symlink atomic swap
        if (!symlinkDataDir.EndsWith("..data")) return false;

        foreach (var (k, v) in updatedData)
        {
            _configurationStore[k] = v;
        }
        return true;
    }
}

using System;

namespace Day44.KubernetesConfigIngress;

/// <summary>
/// Solves LeetCode #647 (Palindromic Substrings) and LeetCode #91 (Decode Ways).
/// </summary>
public static class PalindromicSubstringsAndDecodeWaysSolver
{
    /// <summary>
    /// LC #647: Count total palindromic substrings.
    /// Time Complexity: O(N^2), Space Complexity: O(1).
    /// </summary>
    public static int CountSubstrings(string? s)
    {
        if (string.IsNullOrEmpty(s)) return 0;

        int totalCount = 0;
        for (int i = 0; i < s.Length; i++)
        {
            // Odd length palindromes centered at i
            totalCount += ExpandAndCount(s, i, i);

            // Even length palindromes centered between i and i+1
            totalCount += ExpandAndCount(s, i, i + 1);
        }

        return totalCount;
    }

    private static int ExpandAndCount(string s, int left, int right)
    {
        int count = 0;
        while (left >= 0 && right < s.Length && s[left] == s[right])
        {
            count++;
            left--;
            right++;
        }
        return count;
    }

    /// <summary>
    /// LC #91: Decode Ways ('1'-'26' mapping).
    /// Time Complexity: O(N), Space Complexity: O(1).
    /// </summary>
    public static int NumDecodings(string? s)
    {
        if (string.IsNullOrEmpty(s) || s[0] == '0') return 0;

        int n = s.Length;
        int prev2 = 1; // dp[i-2]
        int prev1 = 1; // dp[i-1]

        for (int i = 1; i < n; i++)
        {
            int current = 0;
            int singleDigit = s[i] - '0';
            int twoDigits = (s[i - 1] - '0') * 10 + singleDigit;

            // Single digit valid transition
            if (singleDigit >= 1 && singleDigit <= 9)
            {
                current += prev1;
            }

            // Two digits valid transition
            if (twoDigits >= 10 && twoDigits <= 26)
            {
                current += prev2;
            }

            prev2 = prev1;
            prev1 = current;
        }

        return prev1;
    }
}

        Assert.Equal("order-service:80", target1);
        Assert.Equal("/v1/checkout", path1);

        Assert.True(matched2);
        Assert.Equal("inventory-service:80", target2);
        Assert.Equal("/items/sku-100", path2);
    }

        var (matchedHost, _, _) = _engine.RouteRequest("rogue.attacker.com", "/orders", true);
        var (matchedPath, _, _) = _engine.RouteRequest("api.company.com", "/unknown-route", true);

                        forwarded = requestPath.Substring(r.PathPrefix.Length);
                        if (!forwarded.StartsWith("/")) forwarded = "/" + forwarded;
                    }
                    return (true, $"{r.TargetService}:{r.TargetPort}", forwarded);
                }
            }
        }
        return (false, null, null);
    }

    public bool SimulateHotReload(string symlinkDataDir, Dictionary<string, string> updatedData)
    {
        // Simulates Kubelet updating the ..data symlink atomic swap
        if (!symlinkDataDir.EndsWith("..data")) return false;

        foreach (var (k, v) in updatedData)
        {
            _configurationStore[k] = v;
        }
        return true;
    }
}

using System;

namespace Day44.KubernetesConfigIngress;

/// <summary>
/// Solves LeetCode #647 (Palindromic Substrings) and LeetCode #91 (Decode Ways).
/// </summary>
public static class PalindromicSubstringsAndDecodeWaysSolver
{
    /// <summary>
    /// LC #647: Count total palindromic substrings.
    /// Time Complexity: O(N^2), Space Complexity: O(1).
    /// </summary>
    public static int CountSubstrings(string? s)
    {
        if (string.IsNullOrEmpty(s)) return 0;

        int totalCount = 0;
        for (int i = 0; i < s.Length; i++)
        {
            // Odd length palindromes centered at i
            totalCount += ExpandAndCount(s, i, i);

            // Even length palindromes centered between i and i+1
            totalCount += ExpandAndCount(s, i, i + 1);
        }

        return totalCount;
    }

    private static int ExpandAndCount(string s, int left, int right)
    {
        int count = 0;
        while (left >= 0 && right < s.Length && s[left] == s[right])
        {
            count++;
            left--;
            right++;
        }
        return count;
    }

    /// <summary>
    /// LC #91: Decode Ways ('1'-'26' mapping).
    /// Time Complexity: O(N), Space Complexity: O(1).
    /// </summary>
    public static int NumDecodings(string? s)
    {
        if (string.IsNullOrEmpty(s) || s[0] == '0') return 0;

        int n = s.Length;
        int prev2 = 1; // dp[i-2]
        int prev1 = 1; // dp[i-1]

        for (int i = 1; i < n; i++)
        {
            int current = 0;
            int singleDigit = s[i] - '0';
            int twoDigits = (s[i - 1] - '0') * 10 + singleDigit;

            // Single digit valid transition
            if (singleDigit >= 1 && singleDigit <= 9)
            {
                current += prev1;
            }

            // Two digits valid transition
            if (twoDigits >= 10 && twoDigits <= 26)
            {
                current += prev2;
            }

            prev2 = prev1;
            prev1 = current;
        }

        return prev1;
    }
}
