Deep Dive Notes: Kubernetes Probes & HPA Auto-Scaling

1. Probe Comparison Matrix

Probe Purpose On Failure Action Target Endpoint
Startup Shield slow bootstrap / cache warmup Kills container after failureThreshold * periodSeconds /health/startup (lightweight check)
Liveness Detect unrecoverable deadlock / loop Kubelet kills container and restarts according to restartPolicy /health/live (process responsiveness)
Readiness Signal readiness to receive user traffic Kubelet unregisters Pod from Service Endpoints /health/ready (deep dependency checks)

2. HPA Control Loop Algorithm

The Horizontal Pod Autoscaler controller executes every 15 seconds by default (--horizontal-pod-autoscaler-sync-period):

$$\text{desiredReplicas} = \left\lceil \text{currentReplicas} \times \frac{\text{currentMetricValue}}{\text{targetMetricValue}} \right\rceil$$

To prevent thrashing, the controller applies:

  1. Tolerance Band: If $|\text{ratio} - 1.0| \le 0.10$, no scaling action is taken.
  2. Stabilization Window: Cool-down period (default 300 seconds for scale-down) picking the maximum recommended replicas over the past 5 minutes before executing scale-down.

Day 45: Kubernetes Probes & Auto-Scaling (HPA)

Overview

Day 45 details production health monitoring and dynamic load scaling in Kubernetes using Startup Probes, Liveness Probes, Readiness Probes, and the Horizontal Pod Autoscaler (HPA).

Core Mechanisms

  • Startup Probe (/health/startup): Protects slow-initializing ASP.NET Core apps (e.g. initial EF Core migrations, cache pre-warming). Disables liveness and readiness checks until passing, preventing premature container restarts.
  • Liveness Probe (/health/live): Detects deadlocks and unrecoverable internal crashes. Failure exceeding failureThreshold causes kubelet to kill the container and restart it.
  • Readiness Probe (/health/ready): Verifies backing dependencies (database, Redis, message broker). Failure temporarily evicts the Pod from Service Endpoints without restarting the container, preventing HTTP 502/503 errors.
  • Horizontal Pod Autoscaler (HPA): Dynamically scales replica count based on CPU utilization, memory pressure, and custom Prometheus metrics (RPS). Includes scale-down stabilization windows (300s) to prevent rapid scaling oscillation (flapping).

DSA Problems

  • LeetCode #322 (Coin Change): Unbounded knapsack dynamic programming in $\mathcal{O}(A \cdot C)$ time and $\mathcal{O}(A)$ space.
  • LeetCode #152 (Maximum Product Subarray): Tracking both running minimum and maximum products to handle negative number sign inversion in $\mathcal{O}(N)$ time and $\mathcal{O}(1)$ space.

10 Senior / Staff-Level Interview Questions with In-Depth Answers:
Q1 Why should you NEVER check downstream database or external API connectivity inside a Liveness Probe?
▼

Answer:

A Liveness Probe answers the question: "Is the process deadlocked or fatally broken such that restarting it will fix it?"

If downstream database or network connectivity fails, restarting the application process will not fix the database. If 50 pods all fail their liveness probe simultaneously due to a database blip, Kubernetes will kill and restart all 50 pods at once, causing a thundering herd on startup, crashing the database further, and amplifying a minor glitch into a total outage.

External dependencies must only be checked in the Readiness Probe.

Q2 How does the Startup Probe solve the dilemma of slow application boot times?
▼

Answer:

Before Startup Probes, developers increased initialDelaySeconds on Liveness Probes (e.g. to 120s). However, if the application crashed during normal operation, Kubernetes would take a full 120s plus threshold intervals to detect the crash and restart the pod.

A Startup Probe allows setting a high threshold (e.g. failureThreshold: 30, periodSeconds: 10 = 300s) during boot. The moment it passes once, the Startup Probe disables itself permanently and the fast Liveness Probe (periodSeconds: 10, timeoutSeconds: 2) takes over immediately.

Q3 What is "flapping" in auto-scaling, and how does Kubernetes HPA mitigate it?
▼

Answer:

Flapping (or thrashing) occurs when a workload scales up due to high load, the increased replica count immediately drops average metric utilization, triggering a rapid scale-down, which in turn causes utilization to spike again in a continuous vicious cycle.

HPA mitigates flapping via:

  1. 10% Tolerance Band: Ignores metric fluctuations within $\pm 10\%$ of the target.
  2. Scale-Down Stabilization Window: Records all computed replica recommendations over the last 300 seconds (5 minutes) and selects the maximum recommended replica count.
Q4 Explain the DP algorithm for LeetCode #322 Coin Change.
▼

Answer:

Let $dp[a]$ be the minimum coins required to make amount $a$.

  • Initialize $dp[0] = 0$ and $dp[1 \dots \text{amount}] = \infty$.
  • For each amount $a$ from 1 to amount:

For each coin $c$ in coins:

If $a - c \ge 0$:

$$dp[a] = \min(dp[a], 1 + dp[a - c])$$

  • If $dp[\text{amount}] == \infty$, return -1; else return $dp[\text{amount}]$.

Time complexity is $\mathcal{O}(\text{Amount} \times \text{Coins.Length})$ and space complexity is $\mathcal{O}(\text{Amount})$.

Q5 Why must you track both `minProduct` and `maxProduct` in LeetCode #152 Maximum Product Subarray?
▼

Answer:

Unlike maximum sum (Kadane's algorithm), multiplying by a negative number reverses the order of magnitude: a large negative number multiplied by another negative number becomes a huge positive number.

Therefore, at each element $x$:

  • If $x < 0$, swap maxProd and minProd.
  • maxProd = max(x, maxProd * x)
  • minProd = min(x, minProd * x)
  • globalMax = max(globalMax, maxProd)

This maintains optimal state in $\mathcal{O}(N)$ time and $\mathcal{O}(1)$ space.

Q7 How does HPA scale workloads based on custom Prometheus metrics like HTTP Requests Per Second (RPS)?
▼

Answer:

  1. Deploy Prometheus Adapter (k8s-prometheus-adapter) which translates Prometheus PromQL queries into Kubernetes Custom Metrics API (custom.metrics.k8s.io).
  2. Configure the HPA metric rule:
metrics:
  - type: Pods
    pods:
      metric:
        name: http_requests_per_second
      target:
        type: AverageValue
        averageValue: 1000
  1. HPA queries the Custom Metrics API, aggregates RPS across pods, and scales replicas up when average RPS exceeds 1000.
Q8 What is the impact of missing or misconfigured Resource Requests when configuring HPA with CPU utilization?
▼

Answer:

HPA computes CPU utilization as a percentage of the Pod's CPU Request, NOT CPU Limit or node capacity.

If a Pod has no CPU Request defined:

$$\text{Utilization} = \frac{\text{Current CPU}}{\text{Request (null)}} = \text{undefined}$$

The HPA controller will fail with unable to get metrics for resource cpu: missing request for cpu and will refuse to scale the deployment.

Q9 What happens if a Pod's readinessProbe fails while it is serving active HTTP requests?
▼

Answer:

  1. The kubelet marks the Pod Ready: False.
  2. The Endpoints controller removes the Pod's IP from the Service's Endpoints object.
  3. Kube-proxy removes the forwarding rules; ingress and other pods stop routing new traffic to this Pod.
  4. Existing in-flight TCP connections remain open and continue processing until finished or closed by the client.
Q10 How do you prevent auto-scaler scale-up delays for sudden traffic bursts?
▼

Answer:

  1. Configure behavior.scaleUp.stabilizationWindowSeconds: 0 for immediate scale-up reaction.
  2. Use selectPolicy: Max with both percentage (e.g. value: 100%) and absolute pod limits (e.g. value: 4 pods).
  3. Set aggressive CPU target utilization (e.g. 60-70%) to give existing replicas buffer room while new pods are scheduled and pulled.
  4. Use KEDA (Kubernetes Event-driven Autoscaling) to scale proactively based on external queue lag (e.g. RabbitMQ messages ready) rather than reactive CPU consumption.

using System;

namespace Day45.KubernetesProbesHPA;

/// <summary>
/// Solves LeetCode #322 (Coin Change) and LeetCode #152 (Maximum Product Subarray).
/// </summary>
public static class CoinChangeAndMaxProductSolver
{
    /// <summary>
    /// LC #322: Fewest coins needed to make up amount.
    /// Bottom-up Unbounded Knapsack DP.
    /// Time: O(Amount * Coins.Length), Space: O(Amount).
    /// </summary>
    public static int CoinChange(int[] coins, int amount)
    {
        if (amount < 0) return -1;
        if (amount == 0) return 0;

        int[] dp = new int[amount + 1];
        Array.Fill(dp, amount + 1);
        dp[0] = 0;

        for (int a = 1; a <= amount; a++)
        {
            foreach (var coin in coins)
            {
                if (a - coin >= 0)
                {
                    dp[a] = Math.Min(dp[a], 1 + dp[a - coin]);
                }
            }
        }

        return dp[amount] > amount ? -1 : dp[amount];
    }

    /// <summary>
    /// LC #152: Maximum Product Subarray.
    /// Tracks max and min running products to handle negative numbers.
    /// Time: O(N), Space: O(1).
    /// </summary>
    public static int MaxProduct(int[] nums)
    {
        if (nums == null || nums.Length == 0) return 0;

        int globalMax = nums[0];
        int currentMax = nums[0];
        int currentMin = nums[0];

        for (int i = 1; i < nums.Length; i++)
        {
            int n = nums[i];

            // If n is negative, swapping max and min prepares for sign flip
            if (n < 0)
            {
                (currentMax, currentMin) = (currentMin, currentMax);
            }

            currentMax = Math.Max(n, currentMax * n);
            currentMin = Math.Min(n, currentMin * n);

            globalMax = Math.Max(globalMax, currentMax);
        }

        return globalMax;
    }
}
📄 src/Day45.KubernetesProbesHPA/KubernetesHpaAndProbeEngine.cs 
using System;

namespace Day45.KubernetesProbesHPA;

public enum ProbeResult { Success, Failure }

public record ProbeState(
    int ConsecutiveFailures,
    int ConsecutiveSuccesses,
    bool IsPassing
);

public class KubernetesHpaAndProbeEngine
{
    public (bool TriggerRestart, bool IsInEndpoints) EvaluateProbes(
        ProbeResult livenessResult,
        ProbeResult readinessResult,
        ref ProbeState livenessState,
        ref ProbeState readinessState,
        int livenessFailureThreshold = 3,
        int readinessFailureThreshold = 2
    )
    {
        // 1. Evaluate Liveness Probe
        bool triggerRestart = false;
        if (livenessResult == ProbeResult.Failure)
        {
            livenessState = livenessState with
            {
                ConsecutiveFailures = livenessState.ConsecutiveFailures + 1,
                ConsecutiveSuccesses = 0,
                IsPassing = false
            };
            if (livenessState.ConsecutiveFailures >= livenessFailureThreshold)
            {
                triggerRestart = true;
            }
        }
        else
        {
            livenessState = livenessState with
            {
                ConsecutiveFailures = 0,
                ConsecutiveSuccesses = livenessState.ConsecutiveSuccesses + 1,
                IsPassing = true
            };
        }

        // 2. Evaluate Readiness Probe
        bool isInEndpoints = readinessState.IsPassing;
        if (readinessResult == ProbeResult.Failure)
        {
            readinessState = readinessState with
            {
                ConsecutiveFailures = readinessState.ConsecutiveFailures + 1,
                ConsecutiveSuccesses = 0,
                IsPassing = false
            };
            if (readinessState.ConsecutiveFailures >= readinessFailureThreshold)
            {
                isInEndpoints = false;
            }
        }
        else
        {
            readinessState = readinessState with
            {
                ConsecutiveFailures = 0,
                ConsecutiveSuccesses = readinessState.ConsecutiveSuccesses + 1,
                IsPassing = true
            };
            isInEndpoints = true;
        }

        return (triggerRestart, isInEndpoints);
    }

    public int CalculateDesiredReplicas(
        int currentReplicas,
        double currentMetricValue,
        double targetMetricValue,
        int minReplicas = 2,
        int maxReplicas = 10,
        double tolerance = 0.1
    )
    {
        if (targetMetricValue <= 0 || currentReplicas <= 0) return currentReplicas;

        double ratio = currentMetricValue / targetMetricValue;

        // Tolerance check: if ratio is within [1 - tolerance, 1 + tolerance], no scaling
        if (Math.Abs(ratio - 1.0) <= tolerance)
        {
            return currentReplicas;
        }

        int desired = (int)Math.Ceiling(currentReplicas * ratio);

        // Clamp between minReplicas and maxReplicas
        if (desired < minReplicas) desired = minReplicas;
        if (desired > maxReplicas) desired = maxReplicas;

        return desired;
    }
}

    {
        var liveness = new ProbeState(0, 0, true);
        var readiness = new ProbeState(0, 0, true);

        // First failure: no restart
        var (restart1, inEndpoints1) = _engine.EvaluateProbes(ProbeResult.Failure, ProbeResult.Success, ref liveness, ref readiness, 3, 2);
        Assert.False(restart1);
        Assert.True(inEndpoints1);

        // Second failure: no restart
        var (restart2, _) = _engine.EvaluateProbes(ProbeResult.Failure, ProbeResult.Success, ref liveness, ref readiness, 3, 2);
        Assert.False(restart2);

        // Third failure: threshold reached, triggers container restart
        var (restart3, _) = _engine.EvaluateProbes(ProbeResult.Failure, ProbeResult.Success, ref liveness, ref readiness, 3, 2);
        Assert.True(restart3);
    }

    [Fact]
    public void Test02_ReadinessProbe_EvictsPodFromServiceEndpointsWithoutRestarting()
    {
        var liveness = new ProbeState(0, 0, true);
        var readiness = new ProbeState(0, 0, true);

        // First failure: threshold is 2
        var (restart1, inEndpoints1) = _engine.EvaluateProbes(ProbeResult.Success, ProbeResult.Failure, ref liveness, ref readiness, 3, 2);
        Assert.False(restart1);
        Assert.True(inEndpoints1);

        // Second failure: readiness threshold exceeded, removed from service endpoints, container NOT restarted
        var (restart2, inEndpoints2) = _engine.EvaluateProbes(ProbeResult.Success, ProbeResult.Failure, ref liveness, ref readiness, 3, 2);
        Assert.False(restart2);
        Assert.False(inEndpoints2);

        Assert.Equal(6, desired);
    }

    [Fact]
    public void Test04_Hpa_AppliesToleranceToPreventFlapping()
    {
        // 4 replicas with 73% CPU vs 70% target -> ratio = 1.042 (within 10% tolerance) -> stays 4
        int desired = _engine.CalculateDesiredReplicas(4, 73.0, 70.0, minReplicas: 2, maxReplicas: 10, tolerance: 0.1);
        Assert.Equal(4, desired);

  2. Use selectPolicy: Max with both percentage (e.g. value: 100%) and absolute pod limits (e.g. value: 4 pods).

using System;

namespace Day45.KubernetesProbesHPA;

/// <summary>
/// Solves LeetCode #322 (Coin Change) and LeetCode #152 (Maximum Product Subarray).
/// </summary>
public static class CoinChangeAndMaxProductSolver
{
    /// <summary>
    /// LC #322: Fewest coins needed to make up amount.
    /// Bottom-up Unbounded Knapsack DP.
    /// Time: O(Amount * Coins.Length), Space: O(Amount).
    /// </summary>
    public static int CoinChange(int[] coins, int amount)
    {
        if (amount < 0) return -1;
        if (amount == 0) return 0;

        int[] dp = new int[amount + 1];
        Array.Fill(dp, amount + 1);
        dp[0] = 0;

        for (int a = 1; a <= amount; a++)
        {
            foreach (var coin in coins)
            {
                if (a - coin >= 0)
                {
                    dp[a] = Math.Min(dp[a], 1 + dp[a - coin]);
                }
            }
        }

        return dp[amount] > amount ? -1 : dp[amount];
    }

    /// <summary>
    /// LC #152: Maximum Product Subarray.
    /// Tracks max and min running products to handle negative numbers.
    /// Time: O(N), Space: O(1).
    /// </summary>
    public static int MaxProduct(int[] nums)
    {
        if (nums == null || nums.Length == 0) return 0;

        int globalMax = nums[0];
        int currentMax = nums[0];
        int currentMin = nums[0];

        for (int i = 1; i < nums.Length; i++)
        {
            int n = nums[i];

            // If n is negative, swapping max and min prepares for sign flip
            if (n < 0)
            {
                (currentMax, currentMin) = (currentMin, currentMax);
            }

            currentMax = Math.Max(n, currentMax * n);
            currentMin = Math.Min(n, currentMin * n);

            globalMax = Math.Max(globalMax, currentMax);
        }

        return globalMax;
    }
}

using System;

namespace Day45.KubernetesProbesHPA;

public enum ProbeResult { Success, Failure }

public record ProbeState(
    int ConsecutiveFailures,
    int ConsecutiveSuccesses,
    bool IsPassing
);

public class KubernetesHpaAndProbeEngine
{
    public (bool TriggerRestart, bool IsInEndpoints) EvaluateProbes(
        ProbeResult livenessResult,
        ProbeResult readinessResult,
        ref ProbeState livenessState,
        ref ProbeState readinessState,
        int livenessFailureThreshold = 3,
        int readinessFailureThreshold = 2
    )
    {
        // 1. Evaluate Liveness Probe
        bool triggerRestart = false;
        if (livenessResult == ProbeResult.Failure)
        {
            livenessState = livenessState with
            {
                ConsecutiveFailures = livenessState.ConsecutiveFailures + 1,
                ConsecutiveSuccesses = 0,
                IsPassing = false
            };
            if (livenessState.ConsecutiveFailures >= livenessFailureThreshold)
            {
                triggerRestart = true;
            }
        }
        else
        {
            livenessState = livenessState with
            {
                ConsecutiveFailures = 0,
                ConsecutiveSuccesses = livenessState.ConsecutiveSuccesses + 1,
                IsPassing = true
            };
        }

        // 2. Evaluate Readiness Probe
        bool isInEndpoints = readinessState.IsPassing;
        if (readinessResult == ProbeResult.Failure)
        {
            readinessState = readinessState with
            {
                ConsecutiveFailures = readinessState.ConsecutiveFailures + 1,
                ConsecutiveSuccesses = 0,
                IsPassing = false
            };
            if (readinessState.ConsecutiveFailures >= readinessFailureThreshold)
            {
                isInEndpoints = false;
            }
        }
        else
        {
            readinessState = readinessState with
            {
                ConsecutiveFailures = 0,
                ConsecutiveSuccesses = readinessState.ConsecutiveSuccesses + 1,
                IsPassing = true
            };
            isInEndpoints = true;
        }

        return (triggerRestart, isInEndpoints);
    }

    public int CalculateDesiredReplicas(
        int currentReplicas,
        double currentMetricValue,
        double targetMetricValue,
        int minReplicas = 2,
        int maxReplicas = 10,
        double tolerance = 0.1
    )
    {
        if (targetMetricValue <= 0 || currentReplicas <= 0) return currentReplicas;

        double ratio = currentMetricValue / targetMetricValue;

        // Tolerance check: if ratio is within [1 - tolerance, 1 + tolerance], no scaling
        if (Math.Abs(ratio - 1.0) <= tolerance)
        {
            return currentReplicas;
        }

        int desired = (int)Math.Ceiling(currentReplicas * ratio);

        // Clamp between minReplicas and maxReplicas
        if (desired < minReplicas) desired = minReplicas;
        if (desired > maxReplicas) desired = maxReplicas;

        return desired;
    }
}
