Deep Dive Notes: Enterprise CI/CD with GitHub Actions

1. Fast Feedback with GitHub Actions Caching

In .NET pipelines, restore and build times are dominated by downloading NuGet packages.

  • Using actions/cache@v4 on ~/.nuget/packages keyed by **/packages.lock.json drops restore times from 45s to 2s.
  • Using Docker Buildx type=gha caches container image layers across workflow runs directly in GitHub's internal cache storage.

2. Supply Chain Security & Container Signing

Modern cloud-native security requires:

  1. Software Bill of Materials (SBOM) generated via Syft in SPDX or CycloneDX format.
  2. Container Signing via Cosign / Sigstore: Keyless signing binding the container image digest to the GitHub Actions OIDC workflow token.
  3. Static Analysis & SAST: Trivy filesystem and image scanning gating pull requests before deployment.

Day 46: CI/CD with GitHub Actions for .NET

Overview

Day 46 focuses on building enterprise-grade Continuous Integration and Continuous Deployment (CI/CD) pipelines for .NET applications using GitHub Actions, automated Trivy security scanning, and GitHub Container Registry (GHCR) image publishing.

Production Pipeline Architecture

  • Lint & Format: Enforces Roslyn code analyzers and format consistency via dotnet format --verify-no-changes.
  • Test with Code Coverage: Executes test suites and collects code coverage using XPlat coverage collectors.
  • Trivy Security Gate: Scans container layers and NuGet dependencies, failing the pipeline if High/Critical vulnerabilities (CVSS $\ge 7.0$) are present with available fixes.
  • Multi-Arch Docker Buildx: Builds and pushes multi-architecture images (linux/amd64, linux/arm64) with GitHub Actions cache backends (type=gha).
  • Semantic Versioning: Automatically computes SemVer releases (vMajor.Minor.Patch) based on Conventional Commits.

DSA Problem: LeetCode #139 (Word Break)

  • 1D Dynamic Programming with boolean array $dp[i]$ indicating if substring $s[0 \dots i-1]$ can be partitioned into dictionary words.
  • Max word length pruning optimizing inner loop to $\mathcal{O}(N \cdot L)$ time.

10 Senior / Staff-Level Interview Questions with In-Depth Answers:
Q1 How do you structure a high-performance CI/CD pipeline in GitHub Actions to achieve sub-3-minute build and test cycles?
▼

Answer:

  1. Parallel Independent Jobs: Separate linting, testing, and security scanning into independent parallel jobs rather than sequential steps.
  2. Aggressive Cache Invalidation: Cache ~/.nuget/packages using actions/cache@v4 with key ${{ runner.os }}-nuget-${{ hashFiles('**/*.csproj', '**/Directory.Packages.props') }}.
  3. No-Restore and No-Build Flags: Pass --no-restore to dotnet build and --no-build to dotnet test.
  4. Docker Layer Caching: Utilize docker/build-push-action with cache-from: type=gha and cache-to: type=gha,mode=max.
Q2 What is the purpose of Trivy vulnerability scanning, and how should security thresholds be enforced in CI?
▼

Answer:

Trivy scans container OS packages (Alpine, Debian, Ubuntu) and application dependencies (NuGet, npm) against CVE databases.

In CI:

  • Set ignore-unfixed: true to avoid blocking builds on vulnerabilities that vendors haven't patched yet.
  • Set severity: CRITICAL,HIGH and exit-code: 1 to fail pull requests only when severe, exploitable CVEs exist.
  • Upload scan results in SARIF format (upload-sarif) to display inline vulnerability alerts in GitHub's Security tab.
Q3 How do GitHub Actions OIDC (OpenID Connect) tokens eliminate static cloud credentials?
▼

Answer:

Traditional CI pipelines stored long-lived static AWS Access Keys or Azure Service Principal secrets in GitHub repository secrets, which risked credential leakage.

With GitHub Actions OIDC:

  1. The GitHub workflow requests a temporary short-lived JWT token signed by GitHub's OIDC Provider.
  2. The cloud provider (AWS/Azure/GCP) validates the JWT signature and claims (sub: repo:owner/repo:ref:refs/heads/main).
  3. The cloud provider assumes a scoped IAM role and returns temporary STS credentials valid for only 1 hour. No permanent secrets are ever stored in GitHub.
Q4 Explain the dynamic programming recurrence for LeetCode #139 Word Break.
▼

Answer:

Let $dp[i]$ be a boolean indicating whether prefix $s[0 \dots i-1]$ can be segmented into words from wordDict.

  • Base case: $dp[0] = true$ (empty string).
  • For $i$ from 1 to $N$:

For $j$ from $i-1$ down to $\max(0, i - L)$ (where $L$ is the max length of any word in the dictionary):

If $dp[j] == true$ and $s[j \dots i-1] \in \text{wordSet}$:

$$dp[i] = true; \quad \text{break}$$

  • Result: $dp[N]$.

Optimizing the inner loop with maximum word length $L$ brings the time complexity down from $\mathcal{O}(N^2)$ to $\mathcal{O}(N \cdot L)$.

Q5 How do Conventional Commits automate Semantic Versioning in CI/CD?
▼

Answer:

Conventional Commits define a structured commit syntax:

  • fix: -> increments PATCH version ($1.0.0 \to 1.0.1$) for backwards-compatible bug fixes.
  • feat: -> increments MINOR version ($1.0.0 \to 1.1.0$) for new backwards-compatible features.
  • feat!:, fix!:, or BREAKING CHANGE: footer -> increments MAJOR version ($1.0.0 \to 2.0.0$) for breaking changes.

Tools like Semantic-Release or GitVersion analyze the commit log between Git tags and automatically tag the repository and publish packages with the exact SemVer version.

Q6 How do you prevent secret leakage in GitHub Actions console logs?
▼

Answer:

  1. Any value retrieved from GitHub Secrets (${{ secrets.MY_SECRET }}) is automatically masked by the GitHub runner (***).
  2. Never format secrets into filenames, URLs, or base64-encoded strings without registering the encoded variant with echo "::add-mask::$ENCODED_SECRET".
  3. Audit pipeline steps to ensure set -x (shell command tracing) is disabled when handling credential variables.
Q7 What are the risks of using `pull_request_target` vs `pull_request` triggers in GitHub Actions?
▼

Answer:

  • pull_request: Runs in the context of the fork/PR branch without access to repository secrets or write permissions. Safe for open-source repositories.
  • pull_request_target: Runs in the context of the target base branch with access to repository secrets. If a malicious PR author modifies a script executed by the workflow, they can exfiltrate repository secrets (PwnRequest vulnerability). Never check out and execute code from the PR head inside a pull_request_target workflow.
Q8 What is the difference between multi-platform Docker builds with QEMU vs native builders?
▼

Answer:

  • QEMU Emulation: Uses software CPU instruction emulation (binfmt_misc) to build ARM64 images on AMD64 runners. Flexible and requires no extra hardware, but CPU-intensive tasks (like compiling .NET code) can be 5–10x slower.
  • Native Cross-Compilation: Uses .NET SDK's built-in cross-compilation (dotnet publish -r linux-arm64) running natively on AMD64 hardware, achieving full native compilation speed while generating ARM64 binaries.
Q9 How do you implement automated rollbacks in a GitHub Actions continuous deployment pipeline?
▼

Answer:

  1. After executing kubectl rollout restart or updating the container image tag in Kubernetes, execute:

kubectl rollout status deployment/order-api --timeout=120s.

  1. If the rollout status times out or fails health probes, the step fails.
  2. In a follow-up step with if: failure(), execute:

kubectl rollout undo deployment/order-api to instantly restore the previous known-good ReplicaSet.

Q10 How does GitHub Container Registry (GHCR) package visibility and permissions integrate with GitHub Actions?
▼

Answer:

Workflows access GHCR without external tokens by utilizing the built-in ${{ secrets.GITHUB_TOKEN }}. Under permissions:, the job declares packages: write and contents: read. Images pushed to ghcr.io/owner/repo automatically inherit the repository's access controls (private or public).

using System;
using System.Collections.Generic;
using System.Linq;

namespace Day46.CiCdGitHubActions;

public record VulnerabilityFinding(
    string PackageId,
    string InstalledVersion,
    string Severity, // "LOW", "MEDIUM", "HIGH", "CRITICAL"
    double CvssScore,
    bool HasFixedVersion
);

public record SemVer(int Major, int Minor, int Patch)
{
    public override string ToString() => $"v{Major}.{Minor}.{Patch}";
}

public class CiCdPipelineEngine
{
    public bool ValidateJobDependencies(Dictionary<string, List<string>> jobDependencies)
    {
        // Cycle detection in job DAG
        var visited = new HashSet<string>();
        var recursionStack = new HashSet<string>();

        foreach (var job in jobDependencies.Keys)
        {
            if (HasCycle(job, jobDependencies, visited, recursionStack))
            {
                return false;
            }
        }
        return true;
    }

    private bool HasCycle(string current, Dictionary<string, List<string>> graph, HashSet<string> visited, HashSet<string> stack)
    {
        if (stack.Contains(current)) return true;
        if (visited.Contains(current)) return false;

        visited.Add(current);
        stack.Add(current);

        if (graph.TryGetValue(current, out var dependencies))
        {
            foreach (var dep in dependencies)
            {
                if (HasCycle(dep, graph, visited, stack)) return true;
            }
        }

        stack.Remove(current);
        return false;
    }

    public (bool Passed, List<string> Violations) EvaluateTrivySecurityGate(
        IEnumerable<VulnerabilityFinding> findings,
        double maxAllowedCvss = 7.0
    )
    {
        var violations = new List<string>();

        foreach (var v in findings)
        {
            if (v.CvssScore >= maxAllowedCvss && v.HasFixedVersion)
            {
                violations.Add($"Security Gate Failed: {v.PackageId} ({v.InstalledVersion}) has {v.Severity} vulnerability with CVSS {v.CvssScore:F1}");
            }
        }

        return (violations.Count == 0, violations);
    }

    public SemVer ComputeNextVersion(SemVer currentVersion, IEnumerable<string> commitMessages)
    {
        bool hasBreakingChange = false;
        bool hasFeature = false;
        bool hasFix = false;

        foreach (var msg in commitMessages)
        {
            var trimmed = msg.Trim();
            if (trimmed.Contains("BREAKING CHANGE:") || trimmed.StartsWith("feat!:") || trimmed.StartsWith("fix!:"))
            {
                hasBreakingChange = true;
            }
            else if (trimmed.StartsWith("feat:") || trimmed.StartsWith("feat("))
            {
                hasFeature = true;
            }
            else if (trimmed.StartsWith("fix:") || trimmed.StartsWith("perf:") || trimmed.StartsWith("refactor:"))
            {
                hasFix = true;
            }
        }

        if (hasBreakingChange)
        {
            return new SemVer(currentVersion.Major + 1, 0, 0);
        }
        if (hasFeature)
        {
            return new SemVer(currentVersion.Major, currentVersion.Minor + 1, 0);
        }
        if (hasFix)
        {
            return new SemVer(currentVersion.Major, currentVersion.Minor, currentVersion.Patch + 1);
        }

        return currentVersion;
    }

    public string MaskSecret(string logOutput, string secretValue)
    {
        if (string.IsNullOrEmpty(secretValue)) return logOutput;
        return logOutput.Replace(secretValue, "***");
    }
}

using System;
using System.Collections.Generic;

namespace Day46.CiCdGitHubActions;

/// <summary>
/// Solves LeetCode #139: Word Break.
/// 1D Dynamic Programming with Dictionary HashSet Lookup.
/// Time Complexity: O(N^2), Space Complexity: O(N + Words).
/// </summary>
public static class WordBreakSolver
{
    public static bool WordBreak(string? s, IList<string>? wordDict)
    {
        if (string.IsNullOrEmpty(s) || wordDict == null || wordDict.Count == 0)
        {
            return false;
        }

        var wordSet = new HashSet<string>(wordDict);
        int n = s.Length;

        // dp[i] represents if s[0 .. i-1] can be segmented into words from wordDict
        bool[] dp = new bool[n + 1];
        dp[0] = true; // empty string is always valid base case

        int maxWordLen = 0;
        foreach (var w in wordDict)
        {
            maxWordLen = Math.Max(maxWordLen, w.Length);
        }

        for (int i = 1; i <= n; i++)
        {
            // Prune inner loop: word length cannot exceed maxWordLen
            for (int j = i - 1; j >= Math.Max(0, i - maxWordLen); j--)
            {
                if (dp[j])
                {
                    string sub = s.Substring(j, i - j);
                    if (wordSet.Contains(sub))
                    {
                        dp[i] = true;
                        break;
                    }
                }
            }
        }

        return dp[n];
    }
}

using System;
using System.Collections.Generic;

namespace Day46.CiCdGitHubActions.Tests;

    private readonly CiCdPipelineEngine _engine;

    public Day46Tests()
    {
        _engine = new CiCdPipelineEngine();
    }

    [Fact]
    public void Test01_PipelineDAG_ValidatesAcyclicJobDependencies()
    {
        var validGraph = new Dictionary<string, List<string>>
        {
            ["lint"] = new(),
            ["test"] = new() { "lint" },
            ["security-scan"] = new() { "test" },
            ["publish"] = new() { "security-scan" }
        };

        Assert.True(_engine.ValidateJobDependencies(validGraph));
    }

    [Fact]
    public void Test02_PipelineDAG_DetectsCircularJobDependencies()
    {
        var cyclicGraph = new Dictionary<string, List<string>>
        {
            ["jobA"] = new() { "jobB" },
            ["jobB"] = new() { "jobC" },
            ["jobC"] = new() { "jobA" } // Circular dependency
        };

        Assert.False(_engine.ValidateJobDependencies(cyclicGraph));
    }

    [Fact]
    public void Test03_TrivySecurityGate_FailsOnCriticalFixedVulnerabilities()
    {
        var findings = new List<VulnerabilityFinding>
        {
            new("System.Text.Json", "8.0.0", "CRITICAL", 8.8, true),
            new("Microsoft.Data.SqlClient", "5.1.0", "LOW", 3.2, false)
        };

        var (passed, violations) = _engine.EvaluateTrivySecurityGate(findings, maxAllowedCvss: 7.0);

        Assert.False(passed);
        Assert.Single(violations);
        Assert.Contains("System.Text.Json", violations[0]);
    }

    [Fact]
    public void Test04_TrivySecurityGate_PassesWhenNoCriticalVulnerabilitiesExist()
    {
        var findings = new List<VulnerabilityFinding>
        {
            new("Serilog", "3.1.0", "LOW", 2.5, false),
            new("Newtonsoft.Json", "13.0.3", "MEDIUM", 5.3, false)
        };

        var (passed, violations) = _engine.EvaluateTrivySecurityGate(findings, maxAllowedCvss: 7.0);

        Assert.True(passed);
        Assert.Empty(violations);
    }

    [Fact]
    public void Test05_SemVer_CalculatesMajorBumpOnBreakingChange()
    {
        var current = new SemVer(1, 4, 2);
        var commits = new[] { "fix: minor typo", "feat!: overhaul order api schema" };

        var next = _engine.ComputeNextVersion(current, commits);

        Assert.Equal("v2.0.0", next.ToString());
    }

    [Fact]
    public void Test06_SemVer_CalculatesMinorBumpOnFeature()
    {
        var current = new SemVer(1, 4, 2);
        var commits = new[] { "feat: add payment refund webhook", "fix: adjust timeout" };

        var next = _engine.ComputeNextVersion(current, commits);

        Assert.Equal("v1.5.0", next.ToString());
    }

    [Fact]
    public void Test07_SemVer_CalculatesPatchBumpOnBugfix()
    {
        var current = new SemVer(1, 4, 2);
        var commits = new[] { "fix: prevent null pointer exception on missing header" };

        var next = _engine.ComputeNextVersion(current, commits);

        Assert.Equal("v1.4.3", next.ToString());
    }

    [Fact]
    public void Test08_SecretMasking_RedactsSensitiveTokensFromLogs()
    {
        string rawLog = "Executing curl with token: ghp_9876543210abcdef to api endpoint";
        string masked = _engine.MaskSecret(rawLog, "ghp_9876543210abcdef");

        Assert.DoesNotContain("ghp_9876543210abcdef", masked);
        Assert.Contains("***", masked);
    }

    [Fact]
    public void Test09_WordBreak_ValidWordSegmentations()
    {
        Assert.True(WordBreakSolver.WordBreak("leetcode", new[] { "leet", "code" }));
        Assert.True(WordBreakSolver.WordBreak("applepenapple", new[] { "apple", "pen" }));
        Assert.True(WordBreakSolver.WordBreak("cars", new[] { "car", "ca", "rs" }));
    }

    [Fact]
    public void Test10_WordBreak_InvalidSegmentationsAndEdgeCases()
    {
        Assert.False(WordBreakSolver.WordBreak("catsandog", new[] { "cats", "dog", "sand", "and", "cat" }));
        Assert.False(WordBreakSolver.WordBreak("", new[] { "test" }));
        Assert.False(WordBreakSolver.WordBreak("test", Array.Empty<string>()));
    }

using System.Collections.Generic;
using System.Linq;

namespace Day46.CiCdGitHubActions;

public record VulnerabilityFinding(
    string PackageId,
    string InstalledVersion,
    string Severity, // "LOW", "MEDIUM", "HIGH", "CRITICAL"
    double CvssScore,
    bool HasFixedVersion
);

public record SemVer(int Major, int Minor, int Patch)
{
    public override string ToString() => $"v{Major}.{Minor}.{Patch}";
}

public class CiCdPipelineEngine
{
    public bool ValidateJobDependencies(Dictionary<string, List<string>> jobDependencies)
    {
        // Cycle detection in job DAG
        var visited = new HashSet<string>();
        var recursionStack = new HashSet<string>();

        foreach (var job in jobDependencies.Keys)
        {
            if (HasCycle(job, jobDependencies, visited, recursionStack))
            {
                return false;
            }
        }
        return true;
    }

    private bool HasCycle(string current, Dictionary<string, List<string>> graph, HashSet<string> visited, HashSet<string> stack)
    {

        if (visited.Contains(current)) return false;

        visited.Add(current);
        stack.Add(current);

        if (graph.TryGetValue(current, out var dependencies))
        {
            foreach (var dep in dependencies)
            {
                if (HasCycle(dep, graph, visited, stack)) return true;
            }
        }

        stack.Remove(current);
        return false;
    }

    public (bool Passed, List<string> Violations) EvaluateTrivySecurityGate(
        IEnumerable<VulnerabilityFinding> findings,
        double maxAllowedCvss = 7.0

    {
        var violations = new List<string>();

            if (v.CvssScore >= maxAllowedCvss && v.HasFixedVersion)
            {
                violations.Add($"Security Gate Failed: {v.PackageId} ({v.InstalledVersion}) has {v.Severity} vulnerability with CVSS {v.CvssScore:F1}");
            }
        }

        return (violations.Count == 0, violations);
    }

    public SemVer ComputeNextVersion(SemVer currentVersion, IEnumerable<string> commitMessages)
    {
        bool hasBreakingChange = false;
        bool hasFeature = false;
        bool hasFix = false;

        foreach (var msg in commitMessages)
        {
            var trimmed = msg.Trim();
            if (trimmed.Contains("BREAKING CHANGE:") || trimmed.StartsWith("feat!:") || trimmed.StartsWith("fix!:"))
            {
                hasBreakingChange = true;
            }
            else if (trimmed.StartsWith("feat:") || trimmed.StartsWith("feat("))
            {
                hasFeature = true;
            }
            else if (trimmed.StartsWith("fix:") || trimmed.StartsWith("perf:") || trimmed.StartsWith("refactor:"))
            {
                hasFix = true;
            }
        }

        if (hasBreakingChange)
        {
            return new SemVer(currentVersion.Major + 1, 0, 0);
        }
        if (hasFeature)
        {
            return new SemVer(currentVersion.Major, currentVersion.Minor + 1, 0);
        }
        if (hasFix)
        {
            return new SemVer(currentVersion.Major, currentVersion.Minor, currentVersion.Patch + 1);
        }

        return currentVersion;
    }

    public string MaskSecret(string logOutput, string secretValue)
    {
        if (string.IsNullOrEmpty(secretValue)) return logOutput;
        return logOutput.Replace(secretValue, "***");
    }
}

using System;
using System.Collections.Generic;

namespace Day46.CiCdGitHubActions;

/// <summary>
/// Solves LeetCode #139: Word Break.
/// 1D Dynamic Programming with Dictionary HashSet Lookup.
/// Time Complexity: O(N^2), Space Complexity: O(N + Words).
/// </summary>
public static class WordBreakSolver
{
    public static bool WordBreak(string? s, IList<string>? wordDict)
    {
        if (string.IsNullOrEmpty(s) || wordDict == null || wordDict.Count == 0)
        {
            return false;
        }

        var wordSet = new HashSet<string>(wordDict);
        int n = s.Length;

        // dp[i] represents if s[0 .. i-1] can be segmented into words from wordDict
        bool[] dp = new bool[n + 1];
        dp[0] = true; // empty string is always valid base case

        int maxWordLen = 0;
        foreach (var w in wordDict)
        {
            maxWordLen = Math.Max(maxWordLen, w.Length);
        }

        for (int i = 1; i <= n; i++)
        {
            // Prune inner loop: word length cannot exceed maxWordLen
            for (int j = i - 1; j >= Math.Max(0, i - maxWordLen); j--)
            {
                if (dp[j])
                {
                    string sub = s.Substring(j, i - j);
                    if (wordSet.Contains(sub))
                    {
                        dp[i] = true;
                        break;
                    }
                }
            }
        }

        return dp[n];
    }
}
