Technical Notes: Terraform IaC & State Management

1. Terraform Dependency DAG Resolution

Terraform builds a Directed Acyclic Graph (DAG) of all resources. If Resource B references azurerm_resource_group.rg.name, an edge rg -> B is added. Kahn's topological sort determines execution tiers:

  • Tier 0: Resources with in-degree 0 (Resource Groups, VPCs).
  • Tier 1: Subnets, Route Tables, Log Workspaces.
  • Tier 2: Managed Databases, Container App Environments.
  • Tier 3: Container Apps, Ingress, DNS records.

2. State File Locking Mechanics

Concurrent terraform apply executions against the same state file cause state truncation and corrupt resource mapping. Remote backends enforce distributed locks:

  • Azure Blob Storage: Blob lease acquisition (x-ms-lease-action: acquire).
  • AWS S3: DynamoDB table with LockID primary key and TTL.
  • Without a valid lease token, Terraform halts with exit code 1.

3. LeetCode #300: Longest Increasing Subsequence

  • DP Approach: dp[i] = max(dp[j] + 1) for $j < i$ and nums[j] < nums[i]. Time: $\mathcal{O}(N^2)$, Space: $\mathcal{O}(N)$.
  • Patience Sorting: Maintain an array of active tails of increasing subsequences. For each element x, binary search finds the smallest tail $\ge x$. If found, replace it; if none, append x. Time: $\mathcal{O}(N \log N)$, Space: $\mathcal{O}(N)$.

10 Senior / Staff-Level Interview Questions with In-Depth Answers:
Q1 How does Terraform manage distributed state locking, and what happens during a network partition?
▼

Answer:

Terraform acquires a state lock before running plan or apply by interacting with the remote backend (e.g. AWS DynamoDB item lock or Azure Blob Storage lease). The lock holds a unique MD5/UUID lease token, host information, and creation timestamp. If a network partition interrupts the client mid-apply, the lock remains orphaned. Engineers must inspect the execution logs to verify no background provisioning is active and manually run terraform force-unlock <LOCK-ID> to release the lease.

Q2 Why is storing secrets in Terraform state dangerous, and how do modern architectures mitigate this?
▼

Answer:

Terraform state files (terraform.tfstate) store resource attributes—including database passwords, private keys, and API tokens—in unencrypted plaintext within the JSON payload. Mitigations include:

  1. Server-side encryption with customer-managed KMS keys (CMK) and strict RBAC on the storage container.
  2. Ephemeral secrets via HashiCorp Vault or Azure Key Vault, retrieving dynamic credentials at runtime rather than baking them into Terraform resources.
  3. Marking outputs as sensitive = true to prevent console and CI/CD log leakage.
Q3 How do you handle configuration drift between live cloud resources and Terraform state?
▼

Answer:

Drift occurs when resources are modified out-of-band via cloud consoles or CLIs. Terraform detects drift during terraform plan by refreshing state against cloud APIs. To remediate:

  • Adopt live change: Update Terraform HCL configuration to match new cloud values.
  • Overwrite live change: Run terraform apply to force the cloud back to the declared configuration.
  • Import existing resources: Use terraform import or Terraform 1.5+ import { ... } blocks to bring untracked resources under IaC management.
Q4 Explain the difference between implicit and explicit dependencies in Terraform.
▼

Answer:

  • Implicit Dependency: Created automatically when a resource attribute references an attribute of another resource (e.g., subnet_id = azurerm_subnet.snet.id). Terraform automatically infers that snet must be created before the dependent resource.
  • Explicit Dependency: Specified using the depends_on = [ ... ] meta-argument. Used when dependencies exist outside direct attribute references, such as waiting for IAM role propagation or database initialization scripts.
Q5 How do you structure Terraform code to minimize blast radius in enterprise environments?
▼

Answer:

Avoid monolithic state files. Divide infrastructure into decoupled state layers with independent workspaces or directories:

  1. Foundation Layer: Networking, VPC, Subnets, DNS, Transit Gateways.
  2. Data Layer: PostgreSQL Flexible Server, Redis caches, S3/Blob storage.
  3. Application Compute Layer: Container Apps, Kubernetes clusters, Lambdas.

Cross-state data is shared using terraform_remote_state data sources or Cloud Parameter Stores/Key Vaults.

Q6 What is the purpose of Terraform modules, and how are version constraints enforced?
▼

Answer:

Modules encapsulate reusable infrastructure blueprints. In production, modules are published to a private registry or Git repository with SemVer tags. Root configurations enforce strict version constraints:

module "postgres" {
  source  = "git::https://github.com/org/tf-modules.git//postgres?ref=v2.4.1"
  version = "~> 2.4.0"
}

This prevents unexpected breaking changes when module maintainers release new versions.

Q7 What are Terraform provisioners (`local-exec`, `remote-exec`) and why are they considered a last resort?
▼

Answer:

Provisioners execute shell commands or configuration management scripts upon resource creation. They are anti-patterns because:

  1. They break declarative idempotency.
  2. They do not track destroyed resources cleanly.
  3. Failures leave resources in a tainted state.

Cloud-init, VM extensions, Kubernetes manifest controllers, and container entrypoints should be favored over provisioners.

Q8 How does Atlantis or Terraform Cloud enhance CI/CD pull request workflows?
▼

Answer:

Atlantis and Terraform Cloud automate PR-driven IaC:

  1. When a PR is opened, a bot runs terraform plan and comments the exact diff directly on the GitHub PR.
  2. Locks the workspace branch to prevent concurrent PR conflicts.
  3. Team leads review the plan diff and comment atlantis apply to execute changes only after approval.
  4. Ensures single-source-of-truth applies directly from the authorized CI runner with credential isolation.
Q9 Contrast the mathematical proofs of O(N^2) DP vs O(N log N) Patience Sorting for LIS.
▼

Answer:

  • O(N^2) DP: Optimal substructure states that the LIS ending at index $i$ is $1 + \max(dp[j])$ for all $j < i$ where $nums[j] < nums[i]$. Checking all $j$ takes $\sum_{i=1}^{N} i =

rac{N(N-1)}{2} = \mathcal{O}(N^2)$ comparisons.

  • Patience Sorting: Elements represent playing cards dealt onto piles. A card can be placed on top of the leftmost pile whose top card is $\ge x$; if none exists, a new pile is created. The top cards of piles form a strictly increasing array at all times. Binary search finds the destination pile in $\mathcal{O}(\log K)$ time. Processing $N$ elements takes $\mathcal{O}(N \log N)$. The number of piles at termination equals the LIS length.
Q10 How do you reconstruct the actual LIS sequence from Patience Sorting?
▼

Answer:

While patience sorting keeps an array of pile tails of length $L$, the tails array itself does not necessarily represent a valid subsequence (as elements are overwritten). To reconstruct:

  1. Maintain an array tailsIdx storing indices in nums corresponding to pile tops.
  2. Maintain a parent[i] array storing the index of the top card of the pile immediately to the left when nums[i] was placed.
  3. At the end, backtrack from tailsIdx[L - 1] through parent pointers to recover the exact elements in reverse order.

namespace Day47.TerraformIaC;

using System;
using System.Collections.Generic;

public class LongestIncreasingSubsequenceSolver
{
    /// <summary>
    /// Classic O(N^2) Dynamic Programming solution.
    /// </summary>
    public static int SolveDp(int[] nums)
    {
        if (nums == null || nums.Length == 0) return 0;

        int n = nums.Length;
        int[] dp = new int[n];
        Array.Fill(dp, 1);
        int maxLen = 1;

        for (int i = 1; i < n; i++)
        {
            for (int j = 0; j < i; j++)
            {
                if (nums[j] < nums[i])
                {
                    dp[i] = Math.Max(dp[i], dp[j] + 1);
                }
            }
            maxLen = Math.Max(maxLen, dp[i]);
        }

        return maxLen;
    }

    /// <summary>
    /// Optimal O(N log N) Patience Sorting with Binary Search.
    /// </summary>
    public static int SolvePatience(int[] nums)
    {
        if (nums == null || nums.Length == 0) return 0;

        var tails = new List<int>();

        foreach (int x in nums)
        {
            int idx = tails.BinarySearch(x);
            if (idx < 0) idx = ~idx;

            if (idx == tails.Count)
            {
                tails.Add(x);
            }
            else
            {
                tails[idx] = x;
            }
        }

        return tails.Count;
    }

    /// <summary>
    /// Reconstructs the actual sequence of Longest Increasing Subsequence.
    /// </summary>
    public static int[] GetActualLis(int[] nums)
    {
        if (nums == null || nums.Length == 0) return Array.Empty<int>();

        int n = nums.Length;
        int[] dp = new int[n];
        int[] prev = new int[n];
        Array.Fill(dp, 1);
        Array.Fill(prev, -1);

        int maxLen = 1;
        int bestEndIndex = 0;

        for (int i = 1; i < n; i++)
        {
            for (int j = 0; j < i; j++)
            {
                if (nums[j] < nums[i] && dp[j] + 1 > dp[i])
                {
                    dp[i] = dp[j] + 1;
                    prev[i] = j;
                }
            }

            if (dp[i] > maxLen)
            {
                maxLen = dp[i];
                bestEndIndex = i;
            }
        }

        var result = new List<int>();
        int curr = bestEndIndex;
        while (curr != -1)
        {
            result.Add(nums[curr]);
            curr = prev[curr];
        }

        result.Reverse();
        return result.ToArray();
    }
}

using System;

using System.Linq;

public record TerraformResource(
    string Type,
    string Name,
    Dictionary<string, object> Attributes,
    List<string>? ExplicitDependsOn = null)
{
    public string Id => $"{Type}.{Name}";
}

public record TerraformVariable(string Name, string Type, object? DefaultValue, bool IsSensitive = false);

public record TerraformOutput(string Name, string ValueExpression, bool IsSensitive = false);

public enum PlanAction
{
    NoOp,
    Create,
    Update,
    Destroy
}

public record ResourcePlan(string ResourceId, PlanAction Action, Dictionary<string, object> Changes);

public class TerraformGraphBuilder
{
    public static List<string> BuildExecutionOrder(List<TerraformResource> resources)
    {
        var resourceMap = resources.ToDictionary(r => r.Id, r => r);
        var inDegree = resources.ToDictionary(r => r.Id, _ => 0);
        var adj = resources.ToDictionary(r => r.Id, _ => new List<string>());

        foreach (var res in resources)
        {
            var dependencies = new HashSet<string>(res.ExplicitDependsOn ?? Enumerable.Empty<string>());

            // Scan attributes for implicit dependencies (references like "azurerm_resource_group.rg.name")
            foreach (var kvp in res.Attributes)
            {
                if (kvp.Value is string strVal)
                {
                    foreach (var candidate in resourceMap.Keys)
                    {
                        if (candidate != res.Id && strVal.Contains(candidate, StringComparison.OrdinalIgnoreCase))
                        {
                            dependencies.Add(candidate);
                        }
                    }
                }
            }

            foreach (var dep in dependencies)
            {
                if (!resourceMap.ContainsKey(dep))
                {
                    throw new InvalidOperationException($"Resource '{res.Id}' depends on unknown resource '{dep}'.");
                }
                adj[dep].Add(res.Id);
                inDegree[res.Id]++;
            }
        }

        // Kahn's algorithm for topological sorting
        var queue = new Queue<string>(inDegree.Where(kvp => kvp.Value == 0).Select(kvp => kvp.Key));
        var order = new List<string>();

        while (queue.Count > 0)
        {
            var curr = queue.Dequeue();
            order.Add(curr);

            foreach (var neighbor in adj[curr])
            {
                inDegree[neighbor]--;
                if (inDegree[neighbor] == 0)
                {
                    queue.Enqueue(neighbor);
                }
            }
        }

        if (order.Count != resources.Count)
        {
            throw new InvalidOperationException("Circular dependency detected in Terraform resource graph!");
        }

        return order;
    }
}

public class TerraformStateLockManager
{
    private readonly object _lock = new();
    private string? _currentLockHolder;
    private string? _activeLeaseToken;

    public bool TryAcquireLock(string lockId, out string leaseToken)
    {
        lock (_lock)
        {
            if (_currentLockHolder != null)
            {
                leaseToken = string.Empty;
                return false;
            }

            _currentLockHolder = lockId;
            _activeLeaseToken = Guid.NewGuid().ToString("N");
            leaseToken = _activeLeaseToken;
            return true;
        }
    }

    public bool ReleaseLock(string lockId, string leaseToken)
    {
        lock (_lock)
        {
            if (_currentLockHolder == lockId && _activeLeaseToken == leaseToken)
            {
                _currentLockHolder = null;
                _activeLeaseToken = null;
                return true;
            }
            return false;
        }
    }

    public bool IsLocked => _currentLockHolder != null;
}

public class TerraformPlanEngine
{
    public static List<ResourcePlan> GeneratePlan(
        List<TerraformResource> desiredResources,
        Dictionary<string, Dictionary<string, object>> currentState)
    {
        var plans = new List<ResourcePlan>();
        var desiredMap = desiredResources.ToDictionary(r => r.Id, r => r);

        // Check for Create and Update
        foreach (var res in desiredResources)
        {
            if (!currentState.TryGetValue(res.Id, out var stateAttrs))
            {
                plans.Add(new ResourcePlan(res.Id, PlanAction.Create, res.Attributes));
            }
            else
            {
                var diff = new Dictionary<string, object>();
                foreach (var attr in res.Attributes)
                {
                    if (!stateAttrs.TryGetValue(attr.Key, out var currentVal) || !Equals(attr.Value, currentVal))
                    {
                        diff[attr.Key] = attr.Value;
                    }
                }

                if (diff.Count > 0)
                {
                    plans.Add(new ResourcePlan(res.Id, PlanAction.Update, diff));
                }
                else
                {
                    plans.Add(new ResourcePlan(res.Id, PlanAction.NoOp, new Dictionary<string, object>()));
                }
            }
        }

        // Check for Destroy
        foreach (var stateId in currentState.Keys)
        {
            if (!desiredMap.ContainsKey(stateId))
            {
                plans.Add(new ResourcePlan(stateId, PlanAction.Destroy, currentState[stateId]));
            }
        }

        return plans;
    }

    public static Dictionary<string, string> RenderOutputs(
        List<TerraformOutput> outputs,
        Dictionary<string, string> computedValues)
    {
        var result = new Dictionary<string, string>();
        foreach (var outDef in outputs)
        {
            var rawVal = computedValues.TryGetValue(outDef.Name, out var val) ? val : "<unknown>";
            result[outDef.Name] = outDef.IsSensitive ? "(sensitive value)" : rawVal;
        }
        return result;
    }

    public static List<string> DetectDrift(
        Dictionary<string, Dictionary<string, object>> tfState,
        Dictionary<string, Dictionary<string, object>> liveCloudState)
    {
        var drifts = new List<string>();

        foreach (var (resId, stateAttrs) in tfState)
        {
            if (!liveCloudState.TryGetValue(resId, out var liveAttrs))
            {
                drifts.Add($"Resource '{resId}' exists in tfstate but is missing in live cloud!");
                continue;
            }

            foreach (var (attrKey, stateVal) in stateAttrs)
            {
                if (!liveAttrs.TryGetValue(attrKey, out var liveVal) || !Equals(stateVal, liveVal))
                {
                    drifts.Add($"Drift in '{resId}': attribute '{attrKey}' expected '{stateVal}', found '{liveVal}'.");
                }
            }
        }

        return drifts;
    }
}

Technical Notes: Terraform IaC & State Management

1. Terraform Dependency DAG Resolution

Terraform builds a Directed Acyclic Graph (DAG) of all resources. If Resource B references azurerm_resource_group.rg.name, an edge rg -> B is added. Kahn's topological sort determines execution tiers:

  • Tier 0: Resources with in-degree 0 (Resource Groups, VPCs).
  • Tier 1: Subnets, Route Tables, Log Workspaces.
  • Tier 2: Managed Databases, Container App Environments.
  • Tier 3: Container Apps, Ingress, DNS records.

2. State File Locking Mechanics

Concurrent terraform apply executions against the same state file cause state truncation and corrupt resource mapping. Remote backends enforce distributed locks:

  • Azure Blob Storage: Blob lease acquisition (x-ms-lease-action: acquire).
  • AWS S3: DynamoDB table with LockID primary key and TTL.
  • Without a valid lease token, Terraform halts with exit code 1.

3. LeetCode #300: Longest Increasing Subsequence

  • DP Approach: dp[i] = max(dp[j] + 1) for $j < i$ and nums[j] < nums[i]. Time: $\mathcal{O}(N^2)$, Space: $\mathcal{O}(N)$.
  • Patience Sorting: Maintain an array of active tails of increasing subsequences. For each element x, binary search finds the smallest tail $\ge x$. If found, replace it; if none, append x. Time: $\mathcal{O}(N \log N)$, Space: $\mathcal{O}(N)$.

Q1 How does Terraform manage distributed state locking, and what happens during a network partition?
▼

Answer:

Terraform acquires a state lock before running plan or apply by interacting with the remote backend (e.g. AWS DynamoDB item lock or Azure Blob Storage lease). The lock holds a unique MD5/UUID lease token, host information, and creation timestamp. If a network partition interrupts the client mid-apply, the lock remains orphaned. Engineers must inspect the execution logs to verify no background provisioning is active and manually run terraform force-unlock <LOCK-ID> to release the lease.

Q2 Why is storing secrets in Terraform state dangerous, and how do modern architectures mitigate this?
▼

Answer:

Terraform state files (terraform.tfstate) store resource attributes—including database passwords, private keys, and API tokens—in unencrypted plaintext within the JSON payload. Mitigations include:

  1. Server-side encryption with customer-managed KMS keys (CMK) and strict RBAC on the storage container.
  2. Ephemeral secrets via HashiCorp Vault or Azure Key Vault, retrieving dynamic credentials at runtime rather than baking them into Terraform resources.
  3. Marking outputs as sensitive = true to prevent console and CI/CD log leakage.
Q3 How do you handle configuration drift between live cloud resources and Terraform state?
▼

Answer:

Drift occurs when resources are modified out-of-band via cloud consoles or CLIs. Terraform detects drift during terraform plan by refreshing state against cloud APIs. To remediate:

  • Adopt live change: Update Terraform HCL configuration to match new cloud values.
  • Overwrite live change: Run terraform apply to force the cloud back to the declared configuration.
  • Import existing resources: Use terraform import or Terraform 1.5+ import { ... } blocks to bring untracked resources under IaC management.
Q4 Explain the difference between implicit and explicit dependencies in Terraform.
▼

Answer:

  • Implicit Dependency: Created automatically when a resource attribute references an attribute of another resource (e.g., subnet_id = azurerm_subnet.snet.id). Terraform automatically infers that snet must be created before the dependent resource.
  • Explicit Dependency: Specified using the depends_on = [ ... ] meta-argument. Used when dependencies exist outside direct attribute references, such as waiting for IAM role propagation or database initialization scripts.
Q5 How do you structure Terraform code to minimize blast radius in enterprise environments?
▼

Answer:

Avoid monolithic state files. Divide infrastructure into decoupled state layers with independent workspaces or directories:

  1. Foundation Layer: Networking, VPC, Subnets, DNS, Transit Gateways.
  2. Data Layer: PostgreSQL Flexible Server, Redis caches, S3/Blob storage.
  3. Application Compute Layer: Container Apps, Kubernetes clusters, Lambdas.

Cross-state data is shared using terraform_remote_state data sources or Cloud Parameter Stores/Key Vaults.

Q6 What is the purpose of Terraform modules, and how are version constraints enforced?
▼

Answer:

Modules encapsulate reusable infrastructure blueprints. In production, modules are published to a private registry or Git repository with SemVer tags. Root configurations enforce strict version constraints:

module "postgres" {
  source  = "git::https://github.com/org/tf-modules.git//postgres?ref=v2.4.1"
  version = "~> 2.4.0"
}

This prevents unexpected breaking changes when module maintainers release new versions.

Q7 What are Terraform provisioners (`local-exec`, `remote-exec`) and why are they considered a last resort?
▼

Answer:

Provisioners execute shell commands or configuration management scripts upon resource creation. They are anti-patterns because:

  1. They break declarative idempotency.
  2. They do not track destroyed resources cleanly.
  3. Failures leave resources in a tainted state.

Cloud-init, VM extensions, Kubernetes manifest controllers, and container entrypoints should be favored over provisioners.

▼

Answer:

Atlantis and Terraform Cloud automate PR-driven IaC:

  1. When a PR is opened, a bot runs terraform plan and comments the exact diff directly on the GitHub PR.
  2. Locks the workspace branch to prevent concurrent PR conflicts.
  3. Team leads review the plan diff and comment atlantis apply to execute changes only after approval.
  4. Ensures single-source-of-truth applies directly from the authorized CI runner with credential isolation.
Q9 Contrast the mathematical proofs of O(N^2) DP vs O(N log N) Patience Sorting for LIS.
▼

Answer:

  • O(N^2) DP: Optimal substructure states that the LIS ending at index $i$ is $1 + \max(dp[j])$ for all $j < i$ where $nums[j] < nums[i]$. Checking all $j$ takes $\sum_{i=1}^{N} i =

rac{N(N-1)}{2} = \mathcal{O}(N^2)$ comparisons.

  • Patience Sorting: Elements represent playing cards dealt onto piles. A card can be placed on top of the leftmost pile whose top card is $\ge x$; if none exists, a new pile is created. The top cards of piles form a strictly increasing array at all times. Binary search finds the destination pile in $\mathcal{O}(\log K)$ time. Processing $N$ elements takes $\mathcal{O}(N \log N)$. The number of piles at termination equals the LIS length.
Q10 How do you reconstruct the actual LIS sequence from Patience Sorting?
▼

Answer:

While patience sorting keeps an array of pile tails of length $L$, the tails array itself does not necessarily represent a valid subsequence (as elements are overwritten). To reconstruct:

  1. Maintain an array tailsIdx storing indices in nums corresponding to pile tops.
  2. Maintain a parent[i] array storing the index of the top card of the pile immediately to the left when nums[i] was placed.
  3. At the end, backtrack from tailsIdx[L - 1] through parent pointers to recover the exact elements in reverse order.

namespace Day47.TerraformIaC;

using System;
using System.Collections.Generic;

public class LongestIncreasingSubsequenceSolver
{
    /// <summary>
    /// Classic O(N^2) Dynamic Programming solution.
    /// </summary>
    public static int SolveDp(int[] nums)
    {
        if (nums == null || nums.Length == 0) return 0;

        int n = nums.Length;
        int[] dp = new int[n];
        Array.Fill(dp, 1);
        int maxLen = 1;

        for (int i = 1; i < n; i++)
        {
            for (int j = 0; j < i; j++)
            {
                if (nums[j] < nums[i])
                {
                    dp[i] = Math.Max(dp[i], dp[j] + 1);
                }
            }
            maxLen = Math.Max(maxLen, dp[i]);
        }

        return maxLen;
    }

    /// <summary>
    /// Optimal O(N log N) Patience Sorting with Binary Search.
    /// </summary>
    public static int SolvePatience(int[] nums)
    {
        if (nums == null || nums.Length == 0) return 0;

        var tails = new List<int>();

        foreach (int x in nums)
        {
            int idx = tails.BinarySearch(x);
            if (idx < 0) idx = ~idx;

            if (idx == tails.Count)
            {
                tails.Add(x);
            }
            else
            {
                tails[idx] = x;
            }
        }

        return tails.Count;
    }

    /// <summary>
    /// Reconstructs the actual sequence of Longest Increasing Subsequence.
    /// </summary>
    public static int[] GetActualLis(int[] nums)
    {
        if (nums == null || nums.Length == 0) return Array.Empty<int>();

        int n = nums.Length;
        int[] dp = new int[n];
        int[] prev = new int[n];
        Array.Fill(dp, 1);
        Array.Fill(prev, -1);

        int maxLen = 1;
        int bestEndIndex = 0;

        for (int i = 1; i < n; i++)
        {
            for (int j = 0; j < i; j++)
            {
                if (nums[j] < nums[i] && dp[j] + 1 > dp[i])
                {
                    dp[i] = dp[j] + 1;
                    prev[i] = j;
                }
            }

            if (dp[i] > maxLen)
            {
                maxLen = dp[i];
                bestEndIndex = i;
            }
        }

        var result = new List<int>();
        int curr = bestEndIndex;
        while (curr != -1)
        {
            result.Add(nums[curr]);
            curr = prev[curr];
        }

        result.Reverse();
        return result.ToArray();
    }
}

public record TerraformOutput(string Name, string ValueExpression, bool IsSensitive = false);

public enum PlanAction
{
    NoOp,
    Create,
    Update,
    Destroy
}

public class TerraformGraphBuilder
{
    public static List<string> BuildExecutionOrder(List<TerraformResource> resources)
    {
        var resourceMap = resources.ToDictionary(r => r.Id, r => r);
        var inDegree = resources.ToDictionary(r => r.Id, _ => 0);
        var adj = resources.ToDictionary(r => r.Id, _ => new List<string>());

        foreach (var res in resources)
        {
            var dependencies = new HashSet<string>(res.ExplicitDependsOn ?? Enumerable.Empty<string>());

            // Scan attributes for implicit dependencies (references like "azurerm_resource_group.rg.name")
            foreach (var kvp in res.Attributes)
            {
                if (kvp.Value is string strVal)
                {
                    foreach (var candidate in resourceMap.Keys)
                    {
                        if (candidate != res.Id && strVal.Contains(candidate, StringComparison.OrdinalIgnoreCase))
                        {
                            dependencies.Add(candidate);
                        }
                    }
                }
            }

            foreach (var dep in dependencies)
            {
                if (!resourceMap.ContainsKey(dep))
                {
                    throw new InvalidOperationException($"Resource '{res.Id}' depends on unknown resource '{dep}'.");
                }
                adj[dep].Add(res.Id);
                inDegree[res.Id]++;
            }
        }

        // Kahn's algorithm for topological sorting
        var queue = new Queue<string>(inDegree.Where(kvp => kvp.Value == 0).Select(kvp => kvp.Key));
        var order = new List<string>();

        while (queue.Count > 0)
        {
            var curr = queue.Dequeue();
            order.Add(curr);

            foreach (var neighbor in adj[curr])
            {
                inDegree[neighbor]--;
                if (inDegree[neighbor] == 0)
                {
                    queue.Enqueue(neighbor);
                }
            }
        }

        if (order.Count != resources.Count)
        {
            throw new InvalidOperationException("Circular dependency detected in Terraform resource graph!");
        }

        return order;
    }
}

public class TerraformStateLockManager
{
    private readonly object _lock = new();
    private string? _currentLockHolder;
    private string? _activeLeaseToken;

    public bool TryAcquireLock(string lockId, out string leaseToken)
    {
        lock (_lock)
        {
            if (_currentLockHolder != null)
            {
                leaseToken = string.Empty;
                return false;
            }

            _currentLockHolder = lockId;
            _activeLeaseToken = Guid.NewGuid().ToString("N");
            leaseToken = _activeLeaseToken;
            return true;
        }
    }

    public bool ReleaseLock(string lockId, string leaseToken)
    {
        lock (_lock)
        {
            if (_currentLockHolder == lockId && _activeLeaseToken == leaseToken)
            {
                _currentLockHolder = null;
                _activeLeaseToken = null;
                return true;
            }
            return false;
        }
    }

    public bool IsLocked => _currentLockHolder != null;
}

public class TerraformPlanEngine
{
    public static List<ResourcePlan> GeneratePlan(
        List<TerraformResource> desiredResources,
        Dictionary<string, Dictionary<string, object>> currentState)
    {
        var plans = new List<ResourcePlan>();
        var desiredMap = desiredResources.ToDictionary(r => r.Id, r => r);

        // Check for Create and Update
        foreach (var res in desiredResources)
        {
            if (!currentState.TryGetValue(res.Id, out var stateAttrs))
            {
                plans.Add(new ResourcePlan(res.Id, PlanAction.Create, res.Attributes));
            }
            else
            {
                var diff = new Dictionary<string, object>();
                foreach (var attr in res.Attributes)
                {
                    if (!stateAttrs.TryGetValue(attr.Key, out var currentVal) || !Equals(attr.Value, currentVal))
                    {
                        diff[attr.Key] = attr.Value;
                    }
                }

                if (diff.Count > 0)
                {
                    plans.Add(new ResourcePlan(res.Id, PlanAction.Update, diff));
                }
                else
                {
                    plans.Add(new ResourcePlan(res.Id, PlanAction.NoOp, new Dictionary<string, object>()));
                }
            }
        }

        // Check for Destroy
        foreach (var stateId in currentState.Keys)
        {
            if (!desiredMap.ContainsKey(stateId))
            {
                plans.Add(new ResourcePlan(stateId, PlanAction.Destroy, currentState[stateId]));
            }
        }

        return plans;
    }

    public static Dictionary<string, string> RenderOutputs(
        List<TerraformOutput> outputs,
        Dictionary<string, string> computedValues)
    {
        var result = new Dictionary<string, string>();
        foreach (var outDef in outputs)
        {
            var rawVal = computedValues.TryGetValue(outDef.Name, out var val) ? val : "<unknown>";
            result[outDef.Name] = outDef.IsSensitive ? "(sensitive value)" : rawVal;
        }
        return result;
    }

    public static List<string> DetectDrift(
        Dictionary<string, Dictionary<string, object>> tfState,
        Dictionary<string, Dictionary<string, object>> liveCloudState)
    {
        var drifts = new List<string>();

        foreach (var (resId, stateAttrs) in tfState)
        {
            if (!liveCloudState.TryGetValue(resId, out var liveAttrs))
            {
                drifts.Add($"Resource '{resId}' exists in tfstate but is missing in live cloud!");
                continue;
            }

            foreach (var (attrKey, stateVal) in stateAttrs)
            {
                if (!liveAttrs.TryGetValue(attrKey, out var liveVal) || !Equals(stateVal, liveVal))
                {
                    drifts.Add($"Drift in '{resId}': attribute '{attrKey}' expected '{stateVal}', found '{liveVal}'.");
                }
            }
        }

        return drifts;
    }
}
