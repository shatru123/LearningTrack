Technical Notes: Cloud Architecture Patterns & Cost Optimization

1. Multi-Region Failover Topologies

  • Active-Passive (Warm Standby): Primary region processes 100% of write traffic; secondary region hosts scaled-down compute and read replicas. Failover requires DNS record update + compute scale-out. RTO: 3–10 minutes, RPO: Asynchronous replication lag (seconds).
  • Active-Active (Dual-Region): Both regions process active reads and writes. Requires distributed conflict resolution (CRDTs, Last-Write-Wins, or partitioned tenancy). RTO: < 1 minute, RPO: Near zero.

2. Cloud Cost & Egress Bandwidth Economics

  • Compute Commitments: On-Demand provides flexibility; 1-year and 3-year Savings Plans / Reserved Instances yield 40%–60% discounts; Spot instances provide up to 75%–90% discounts for fault-tolerant workers.
  • Egress Bandwidth Tax: Public internet egress is charged at ~$0.09/GB; inter-region traffic at ~$0.02/GB; inter-AZ at ~$0.01/GB. Routing intra-cloud traffic via Private Endpoints (Azure Private Link / AWS PrivateLink) eliminates public internet traversal and reduces egress fees to zero.

3. LeetCode #416: Partition Equal Subset Sum

  • Target sum $S = ext{totalSum} / 2$. If $ ext{totalSum}$ is odd, return false.
  • State Transition: dp[j] = dp[j] || dp[j - num].
  • Reverse traversal in 1D array ($j = ext{target} \dots ext{num}$) ensures each element is used at most once (0/1 Knapsack property).

Day 48: Cloud Architecture Patterns (AWS/Azure)

Overview

Enterprise distributed systems running in public cloud providers (AWS, Azure) must guarantee business continuity across catastrophic regional outages while optimizing cloud spend. Day 48 explores multi-region failover (Active-Passive vs Active-Active), database replication lag bounds, blob storage lifecycle tiering, cloud compute and egress cost optimization, and LeetCode #416 Partition Equal Subset Sum (0/1 Knapsack variation).

Key Concepts

  • Multi-Region Failover Architecture: Warm Standby / Pilot Light vs Active-Active dual-write topologies with Azure Front Door / AWS Route 53 health probing.
  • RTO & RPO Metrics: Calculating Recovery Time Objective (RTO) and Recovery Point Objective (RPO) based on DNS propagation and asynchronous replication lag.
  • Storage Lifecycle Policy: Transitioning unaccessed objects through Hot, Cool, Cold, and Archive tiers.
  • FinOps & Cost Optimization: Maximizing compute savings through Reserved Instances and Spot instances; eliminating data egress bandwidth taxes via Private Endpoints.
  • Algorithm (LC #416): Partition Equal Subset Sum solved via 0/1 knapsack 2D DP table and space-optimized 1D boolean array.
10 Senior / Staff-Level Interview Questions with In-Depth Answers:
Q1 Compare Active-Passive (Pilot Light vs Warm Standby) and Active-Active multi-region architectures.
▼

Answer:

  • Pilot Light: Core data is replicated continuously (e.g. database replica, storage sync), but compute resources are off or minimal (e.g. AMIs/container images ready). During disaster recovery, compute must be provisioned. RTO: 15–30 minutes, Low cost.
  • Warm Standby: Compute runs at a reduced capacity (e.g. 20% replicas) alongside hot database read replicas. During failover, autoscaling ramps compute to 100%. RTO: 3–5 minutes, Moderate cost.
  • Active-Active: Full compute and multi-primary or multi-write data layers run in 2+ regions simultaneously. Traffic is routed via latency or geoproximity. RTO: < 30 seconds, Highest cost and engineering complexity (handling split-brain and write conflicts).
Q2 What are RTO and RPO, and how do you design systems to meet strict financial SLAs?
▼

Answer:

  • Recovery Time Objective (RTO): Maximum acceptable duration of downtime before system recovery.
  • Recovery Point Objective (RPO): Maximum acceptable age of data lost due to a disaster event.

For strict financial SLAs (e.g., RTO < 1 min, RPO = 0), synchronous multi-region replication (or 3-AZ synchronous quorum like AWS Aurora Global DB or Azure Cosmos DB multi-region strong consistency) is required. If asynchronous replication is used, RPO equals the replication lag; any un-replicated commits at failover time represent permanent data loss.

Q3 How do you prevent split-brain during automated regional failover?
▼

Answer:

When primary and secondary regions lose connectivity, the secondary might assume the primary died and self-promote, causing concurrent divergent writes. Mitigations:

  1. Third-Party Quorum / Witness: A lightweight arbiter in a 3rd independent region or global consensus service (Route 53 ARC / Front Door health check controller) must vote on leader promotion.
  2. Fencing Tokens: Use epoch-based fencing tokens on shared storage or databases to invalidate requests from a split-brained former primary.
  3. Automated Demotion / STONITH: Shoot The Other Node In The Head—the orchestration platform revokes IAM permissions or shuts down ingress on the primary before promoting the secondary.
Q4 How do cloud egress charges affect microservices architecture, and how do you optimize them?
▼

Answer:

Data egress across availability zones (~$0.01/GB), regions (~$0.02/GB), and the internet (~$0.09/GB) constitutes a major portion of cloud bills. Optimizations:

  1. AZ Affinity: Co-locate high-bandwidth chatty microservices within the same Availability Zone where possible.
  2. Private Endpoints: Use Azure Private Link or AWS VPC Endpoints to route traffic internally rather than traversing public IPs.
  3. Edge Caching: Deploy CloudFront or Azure Front Door with gzip/Brotli compression to cache static assets and API responses at the edge.
  4. Binary Protocols: Replace large verbose JSON payloads with Protobuf or MessagePack to reduce wire payload sizes by 60–80%.
Q5 How do you architect workloads to safely leverage Spot / Preemptible instances?
▼

Answer:

Spot instances offer up to 90% savings but can be terminated by the cloud provider with a 30-to-120-second warning notice. Best practices:

  1. Stateless & Resumable Tasks: Use Spot for background video transcoding, batch processing, and queue workers (RabbitMQ/SQS), where failed tasks are retried via Dead Letter Queues.
  2. Termination Hook Listeners: Monitor AWS EC2 Metadata service (/latest/meta-data/spot/instance-action) or Azure Scheduled Events to gracefully drain connections and checkpoint progress within the grace period.
  3. Mixed Instance Pools: Combine 20–30% On-Demand baseline capacity with 70–80% Spot instances across diverse instance types and availability zones.
Q6 How does Azure Cosmos DB or AWS DynamoDB handle multi-region conflict resolution in Active-Active?
▼

Answer:

When concurrent writes occur on the same record in different regions:

  • Last-Write-Wins (LWW): Uses UTC timestamps to select the latest write. Susceptible to clock skew (NTP drift).
  • Custom Conflict Resolution / Stored Procedures: Application code merges fields (e.g. merging shopping cart item arrays).
  • CRDTs (Conflict-free Replicated Data Types): Commutative operations (incrementing counters, add-only sets) converge mathematically without central coordination.
Q7 Explain the trade-offs of Object Storage Lifecycle Tiering (Hot, Cool, Cold, Archive).
▼

Answer:

  • Hot: Lowest access/retrieval fee, highest storage cost (~$0.018/GB). Ideal for active, frequently accessed data.
  • Cool: Lower storage cost (~$0.010/GB), small retrieval fee, 30-day minimum retention.
  • Cold: Even lower storage cost (~$0.0045/GB), moderate retrieval fee, 90-day minimum retention.
  • Archive: Extremely low storage cost (~$0.00099/GB), highest retrieval fee, hours of retrieval latency (rehydration), 180-day minimum retention.

Trap: Prematurely moving frequently accessed data to Archive can incur exorbitant retrieval and early-deletion penalty fees.

Q8 What is Cloud FinOps and how does it integrate into the engineering lifecycle?
▼

Answer:

FinOps is the operational framework bringing financial accountability to cloud engineering:

  1. Tagging & Cost Allocation: Enforcing mandatory tags (CostCenter, Environment, ServiceOwner) via Azure Policy or AWS SCPs.
  2. Unit Economics: Measuring cost per business transaction (e.g., cost per order processed, cost per active user).
  3. Right-Sizing & Auto-Shutdown: Automated scripts terminating idle dev/test environments overnight and scaling down overprovisioned VM/container SKUs based on P95 utilization.
Q9 Why must the 1D dynamic programming array for 0/1 Knapsack be traversed backwards?
▼

Answer:

In 0/1 Knapsack, each item can be chosen at most once. If we traverse the DP array forwards ($j = num \dots target$):

dp[j] = dp[j] || dp[j - num] would use the updated value of dp[j - num] from the same item iteration, effectively allowing the same item to be reused multiple times (which solves the Unbounded Knapsack problem). Traversing backwards ($j = target \dots num$) guarantees that dp[j - num] reflects the state from the previous item iteration.

Q10 How can Bitset / BigInteger optimization accelerate Partition Equal Subset Sum?
▼

Answer:

The boolean DP array transition can be viewed as shifting a bitmask:

bitset = bitset | (bitset << num)

With bitwise operations, a 64-bit integer can compute 64 states simultaneously using CPU SIMD instructions. For target sums up to $10^5$, a bitset evaluates the knapsack in $\mathcal{O}(N \cdot ext{Target} / 64)$ operations—yielding a 50x–60x speedup over standard boolean arrays.

namespace Day48.CloudArchitecture;

using System;
using System.Collections.Generic;
using System.Linq;

public enum RoutingMode
{
    ActivePassiveWarmStandby,
    ActiveActive
}

public record RegionHealth(string Region, bool IsHealthy, double LatencyMs, double ErrorRatePercent);

public class MultiRegionTrafficRouter
{
    public RoutingMode Mode { get; }
    public string PrimaryRegion { get; }
    public string SecondaryRegion { get; }
    public double ErrorRateFailoverThreshold { get; set; } = 20.0; // percent

    public MultiRegionTrafficRouter(
        string primaryRegion,
        string secondaryRegion,
        RoutingMode mode = RoutingMode.ActivePassiveWarmStandby)
    {
        PrimaryRegion = primaryRegion;
        SecondaryRegion = secondaryRegion;
        Mode = mode;
    }

    public string RouteTraffic(RegionHealth primaryHealth, RegionHealth secondaryHealth)
    {
        if (Mode == RoutingMode.ActivePassiveWarmStandby)
        {
            if (primaryHealth.IsHealthy && primaryHealth.ErrorRatePercent < ErrorRateFailoverThreshold)
            {
                return PrimaryRegion;
            }

            if (secondaryHealth.IsHealthy)
            {
                return SecondaryRegion;
            }

            // Both degraded: route to the one with lower error rate
            return primaryHealth.ErrorRatePercent <= secondaryHealth.ErrorRatePercent
                ? PrimaryRegion
                : SecondaryRegion;
        }
        else // ActiveActive
        {
            if (!primaryHealth.IsHealthy && secondaryHealth.IsHealthy) return SecondaryRegion;
            if (primaryHealth.IsHealthy && !secondaryHealth.IsHealthy) return PrimaryRegion;

            // Route to region with lowest latency
            return primaryHealth.LatencyMs <= secondaryHealth.LatencyMs ? PrimaryRegion : SecondaryRegion;
        }
    }

    public (int rtoMinutes, int rpoSeconds) EstimateDisasterRecoveryBounds(double replicationLagSec)
    {
        if (Mode == RoutingMode.ActivePassiveWarmStandby)
        {
            // Warm standby takes ~2-5 mins DNS propagation + warm up, RPO is DB replication lag
            int rto = 5;
            int rpo = (int)Math.Ceiling(replicationLagSec);
            return (rto, rpo);
        }
        else // Active-Active
        {
            // Immediate automated failover (< 1 min), RPO near 0 or replication lag
            int rto = 1;
            int rpo = (int)Math.Ceiling(replicationLagSec);
            return (rto, rpo);
        }
    }
}

public class DatabaseReplicationLagTracker
{
    public double CurrentLagMilliseconds { get; private set; }

    public void RecordReplicationEvent(DateTime primaryCommitTime, DateTime replicaApplyTime)
    {
        CurrentLagMilliseconds = Math.Max(0, (replicaApplyTime - primaryCommitTime).TotalMilliseconds);
    }

    public bool IsReadConsistent(double maxAcceptableStalenessMs)
    {
        return CurrentLagMilliseconds <= maxAcceptableStalenessMs;
    }
}

public enum StorageTier
{
    Hot,
    Cool,
    Cold,
    Archive
}

public class BlobStorageLifecycleEngine
{
    public static StorageTier EvaluateTier(int daysSinceModified)
    {
        if (daysSinceModified >= 180) return StorageTier.Archive;
        if (daysSinceModified >= 90) return StorageTier.Cold;
        if (daysSinceModified >= 30) return StorageTier.Cool;
        return StorageTier.Hot;
    }

    public static double CalculateMonthlyStorageCost(double sizeGb, StorageTier tier)
    {
        // Indicative Azure/AWS pricing per GB/month:
        // Hot: $0.018/GB, Cool: $0.010/GB, Cold: $0.0045/GB, Archive: $0.00099/GB
        double rate = tier switch
        {
            StorageTier.Hot => 0.018,
            StorageTier.Cool => 0.010,
            StorageTier.Cold => 0.0045,
            StorageTier.Archive => 0.00099,
            _ => 0.018
        };
        return sizeGb * rate;
    }
}

public class CloudCostOptimizationCalculator
{
    public static double ComputeMonthlyComputeCost(int instances, double hourlyOnDemandRate, string commitmentType)
    {
        double hourlyRate = commitmentType.ToLowerInvariant() switch
        {
            "ondemand" => hourlyOnDemandRate,
            "1year_reserved" => hourlyOnDemandRate * 0.60, // 40% discount
            "3year_reserved" => hourlyOnDemandRate * 0.40, // 60% discount
            "spot" => hourlyOnDemandRate * 0.25,           // 75% discount
            _ => hourlyOnDemandRate
        };

        return instances * hourlyRate * 730; // 730 average hours per month
    }

    public static double CalculateEgressCost(double gigabytesTransferred, string transferType)
    {
        // Pricing per GB:
        // Internet egress: $0.09/GB
        // Inter-region egress: $0.02/GB
        // Inter-AZ egress: $0.01/GB
        // Private endpoint / intra-VNet: $0.00/GB
        double rate = transferType.ToLowerInvariant() switch
        {
            "internet" => 0.09,
            "inter_region" => 0.02,
            "inter_az" => 0.01,
            "private_endpoint" => 0.00,
            _ => 0.09
        };

        return gigabytesTransferred * rate;
    }
}

namespace Day48.CloudArchitecture;

using System;
using System.Linq;

public class PartitionEqualSubsetSumSolver
{
    /// <summary>
    /// LeetCode #416: Partition Equal Subset Sum.
    /// Classic 2D Dynamic Programming solution O(N * Target).
    /// </summary>
    public static bool CanPartition2D(int[] nums)
    {
        if (nums == null || nums.Length <= 1) return false;

        int totalSum = nums.Sum();
        if (totalSum % 2 != 0) return false; // Odd sum cannot be partitioned equally

        int target = totalSum / 2;
        int n = nums.Length;
        bool[,] dp = new bool[n + 1, target + 1];

        for (int i = 0; i <= n; i++)
        {
            dp[i, 0] = true; // sum 0 is always achievable with empty subset
        }

        for (int i = 1; i <= n; i++)
        {
            int num = nums[i - 1];
            for (int j = 1; j <= target; j++)
            {
                if (j >= num)
                {
                    dp[i, j] = dp[i - 1, j] || dp[i - 1, j - num];
                }
                else
                {
                    dp[i, j] = dp[i - 1, j];
                }
            }
        }

        return dp[n, target];
    }

    /// <summary>
    /// Space-optimized 1D boolean array DP running right-to-left O(Target) space.
    /// </summary>
    public static bool CanPartition1D(int[] nums)
    {
        if (nums == null || nums.Length <= 1) return false;

        int totalSum = nums.Sum();
        if (totalSum % 2 != 0) return false;

        int target = totalSum / 2;
        bool[] dp = new bool[target + 1];
        dp[0] = true;

        foreach (int num in nums)
        {
            for (int j = target; j >= num; j--)
            {
                if (dp[j - num])
                {
                    dp[j] = true;
                }
            }
            if (dp[target]) return true; // Early exit
        }

        return dp[target];
    }
}

Spot instances offer up to 90% savings but can be terminated by the cloud provider with a 30-to-120-second warning notice. Best practices:

  1. Stateless & Resumable Tasks: Use Spot for background video transcoding, batch processing, and queue workers (RabbitMQ/SQS), where failed tasks are retried via Dead Letter Queues.
  2. Termination Hook Listeners: Monitor AWS EC2 Metadata service (/latest/meta-data/spot/instance-action) or Azure Scheduled Events to gracefully drain connections and checkpoint progress within the grace period.
  3. Mixed Instance Pools: Combine 20–30% On-Demand baseline capacity with 70–80% Spot instances across diverse instance types and availability zones.
Q6 How does Azure Cosmos DB or AWS DynamoDB handle multi-region conflict resolution in Active-Active?
▼

Answer:

When concurrent writes occur on the same record in different regions:

  • Last-Write-Wins (LWW): Uses UTC timestamps to select the latest write. Susceptible to clock skew (NTP drift).
  • Custom Conflict Resolution / Stored Procedures: Application code merges fields (e.g. merging shopping cart item arrays).
  • CRDTs (Conflict-free Replicated Data Types): Commutative operations (incrementing counters, add-only sets) converge mathematically without central coordination.
Q7 Explain the trade-offs of Object Storage Lifecycle Tiering (Hot, Cool, Cold, Archive).
▼

Answer:

  • Hot: Lowest access/retrieval fee, highest storage cost (~$0.018/GB). Ideal for active, frequently accessed data.
  • Cool: Lower storage cost (~$0.010/GB), small retrieval fee, 30-day minimum retention.
  • Cold: Even lower storage cost (~$0.0045/GB), moderate retrieval fee, 90-day minimum retention.
  • Archive: Extremely low storage cost (~$0.00099/GB), highest retrieval fee, hours of retrieval latency (rehydration), 180-day minimum retention.

Trap: Prematurely moving frequently accessed data to Archive can incur exorbitant retrieval and early-deletion penalty fees.

Q8 What is Cloud FinOps and how does it integrate into the engineering lifecycle?
▼

Answer:

FinOps is the operational framework bringing financial accountability to cloud engineering:

  1. Tagging & Cost Allocation: Enforcing mandatory tags (CostCenter, Environment, ServiceOwner) via Azure Policy or AWS SCPs.
  2. Unit Economics: Measuring cost per business transaction (e.g., cost per order processed, cost per active user).
  3. Right-Sizing & Auto-Shutdown: Automated scripts terminating idle dev/test environments overnight and scaling down overprovisioned VM/container SKUs based on P95 utilization.
Q9 Why must the 1D dynamic programming array for 0/1 Knapsack be traversed backwards?
▼

Answer:

In 0/1 Knapsack, each item can be chosen at most once. If we traverse the DP array forwards ($j = num \dots target$):

dp[j] = dp[j] || dp[j - num] would use the updated value of dp[j - num] from the same item iteration, effectively allowing the same item to be reused multiple times (which solves the Unbounded Knapsack problem). Traversing backwards ($j = target \dots num$) guarantees that dp[j - num] reflects the state from the previous item iteration.

Q10 How can Bitset / BigInteger optimization accelerate Partition Equal Subset Sum?
▼

Answer:

The boolean DP array transition can be viewed as shifting a bitmask:

bitset = bitset | (bitset << num)

With bitwise operations, a 64-bit integer can compute 64 states simultaneously using CPU SIMD instructions. For target sums up to $10^5$, a bitset evaluates the knapsack in $\mathcal{O}(N \cdot ext{Target} / 64)$ operations—yielding a 50x–60x speedup over standard boolean arrays.

namespace Day48.CloudArchitecture;

using System;
using System.Collections.Generic;
using System.Linq;

public enum RoutingMode
{
    ActivePassiveWarmStandby,
    ActiveActive
}

public record RegionHealth(string Region, bool IsHealthy, double LatencyMs, double ErrorRatePercent);

public class MultiRegionTrafficRouter
{
    public RoutingMode Mode { get; }
    public string PrimaryRegion { get; }
    public string SecondaryRegion { get; }
    public double ErrorRateFailoverThreshold { get; set; } = 20.0; // percent

    public MultiRegionTrafficRouter(
        string primaryRegion,
        string secondaryRegion,
        RoutingMode mode = RoutingMode.ActivePassiveWarmStandby)
    {
        PrimaryRegion = primaryRegion;
        SecondaryRegion = secondaryRegion;
        Mode = mode;
    }

    public string RouteTraffic(RegionHealth primaryHealth, RegionHealth secondaryHealth)
    {
        if (Mode == RoutingMode.ActivePassiveWarmStandby)
        {
            if (primaryHealth.IsHealthy && primaryHealth.ErrorRatePercent < ErrorRateFailoverThreshold)
            {
                return PrimaryRegion;
            }

            if (secondaryHealth.IsHealthy)
            {
                return SecondaryRegion;
            }

            // Both degraded: route to the one with lower error rate
            return primaryHealth.ErrorRatePercent <= secondaryHealth.ErrorRatePercent
                ? PrimaryRegion
                : SecondaryRegion;
        }
        else // ActiveActive
        {
            if (!primaryHealth.IsHealthy && secondaryHealth.IsHealthy) return SecondaryRegion;
            if (primaryHealth.IsHealthy && !secondaryHealth.IsHealthy) return PrimaryRegion;

            // Route to region with lowest latency
            return primaryHealth.LatencyMs <= secondaryHealth.LatencyMs ? PrimaryRegion : SecondaryRegion;
        }
    }

    public (int rtoMinutes, int rpoSeconds) EstimateDisasterRecoveryBounds(double replicationLagSec)
    {
        if (Mode == RoutingMode.ActivePassiveWarmStandby)
        {
            // Warm standby takes ~2-5 mins DNS propagation + warm up, RPO is DB replication lag
            int rto = 5;
            int rpo = (int)Math.Ceiling(replicationLagSec);
            return (rto, rpo);
        }
        else // Active-Active
        {
            // Immediate automated failover (< 1 min), RPO near 0 or replication lag
            int rto = 1;
            int rpo = (int)Math.Ceiling(replicationLagSec);
            return (rto, rpo);
        }
    }
}

public class DatabaseReplicationLagTracker
{
    public double CurrentLagMilliseconds { get; private set; }

    public void RecordReplicationEvent(DateTime primaryCommitTime, DateTime replicaApplyTime)
    {
        CurrentLagMilliseconds = Math.Max(0, (replicaApplyTime - primaryCommitTime).TotalMilliseconds);
    }

    public bool IsReadConsistent(double maxAcceptableStalenessMs)
    {
        return CurrentLagMilliseconds <= maxAcceptableStalenessMs;
    }
}

    Hot,
    Cool,
    Cold,
    Archive

public class BlobStorageLifecycleEngine

    public static StorageTier EvaluateTier(int daysSinceModified)
    {
        if (daysSinceModified >= 180) return StorageTier.Archive;
        if (daysSinceModified >= 90) return StorageTier.Cold;
        if (daysSinceModified >= 30) return StorageTier.Cool;
        return StorageTier.Hot;
    }

    public static double CalculateMonthlyStorageCost(double sizeGb, StorageTier tier)
    {
        // Indicative Azure/AWS pricing per GB/month:
        // Hot: $0.018/GB, Cool: $0.010/GB, Cold: $0.0045/GB, Archive: $0.00099/GB
        double rate = tier switch
        {
            StorageTier.Hot => 0.018,
            StorageTier.Cool => 0.010,
            StorageTier.Cold => 0.0045,
            StorageTier.Archive => 0.00099,
            _ => 0.018
        };
        return sizeGb * rate;
    }
}

public class CloudCostOptimizationCalculator
{
    public static double ComputeMonthlyComputeCost(int instances, double hourlyOnDemandRate, string commitmentType)
    {
        double hourlyRate = commitmentType.ToLowerInvariant() switch
        {
            "ondemand" => hourlyOnDemandRate,
            "1year_reserved" => hourlyOnDemandRate * 0.60, // 40% discount
            "3year_reserved" => hourlyOnDemandRate * 0.40, // 60% discount
            "spot" => hourlyOnDemandRate * 0.25,           // 75% discount
            _ => hourlyOnDemandRate
        };

        return instances * hourlyRate * 730; // 730 average hours per month
    }

    public static double CalculateEgressCost(double gigabytesTransferred, string transferType)
    {
        // Pricing per GB:
        // Internet egress: $0.09/GB
        // Inter-region egress: $0.02/GB
        // Inter-AZ egress: $0.01/GB
        // Private endpoint / intra-VNet: $0.00/GB
        double rate = transferType.ToLowerInvariant() switch
        {
            "internet" => 0.09,
            "inter_region" => 0.02,
            "inter_az" => 0.01,
            "private_endpoint" => 0.00,
            _ => 0.09
        };

        return gigabytesTransferred * rate;
    }
}

namespace Day48.CloudArchitecture;

using System;
using System.Linq;

public class PartitionEqualSubsetSumSolver
{
    /// <summary>
    /// LeetCode #416: Partition Equal Subset Sum.
    /// Classic 2D Dynamic Programming solution O(N * Target).
    /// </summary>
    public static bool CanPartition2D(int[] nums)
    {
        if (nums == null || nums.Length <= 1) return false;

        int totalSum = nums.Sum();
        if (totalSum % 2 != 0) return false; // Odd sum cannot be partitioned equally

        int target = totalSum / 2;
        int n = nums.Length;
        bool[,] dp = new bool[n + 1, target + 1];

        for (int i = 0; i <= n; i++)
        {
            dp[i, 0] = true; // sum 0 is always achievable with empty subset
        }

        for (int i = 1; i <= n; i++)
        {
            int num = nums[i - 1];
            for (int j = 1; j <= target; j++)
            {
                if (j >= num)
                {
                    dp[i, j] = dp[i - 1, j] || dp[i - 1, j - num];
                }
                else
                {
                    dp[i, j] = dp[i - 1, j];
                }
            }
        }

        return dp[n, target];
    }

    /// <summary>
    /// Space-optimized 1D boolean array DP running right-to-left O(Target) space.
    /// </summary>
    public static bool CanPartition1D(int[] nums)
    {
        if (nums == null || nums.Length <= 1) return false;

        int totalSum = nums.Sum();
        if (totalSum % 2 != 0) return false;

        int target = totalSum / 2;
        bool[] dp = new bool[target + 1];
        dp[0] = true;

        foreach (int num in nums)
        {
            for (int j = target; j >= num; j--)
            {
                if (dp[j - num])
                {
                    dp[j] = true;
                }
            }
            if (dp[target]) return true; // Early exit
        }

        return dp[target];
    }
}
