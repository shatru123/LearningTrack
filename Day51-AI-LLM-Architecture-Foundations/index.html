Technical Notes: Transformer Architecture & LLM Foundations

1. Scaled Dot-Product & Causal Attention Mechanics

  • Scale Factor $\sqrt{d_k}$: For large projection dimensions $d_k$, the dot product $QK^T$ grows large in magnitude, pushing the softmax function into regions with near-zero gradients (vanishing gradient problem). Dividing by $\sqrt{d_k}$ stabilizes variance to 1.0.
  • Causal Masking: In decoder-only architectures (GPT, Llama, Mistral), token $i$ must not attend to token $j > i$. Applying an upper-triangular mask of $-\infty$ ensures that $\exp(-\infty) = 0$ after softmax, preserving strict autoregression.

2. Tokenization & Sampling Mechanics

  • Byte-Pair Encoding (BPE): Subword tokenization iteratively merges the most frequent adjacent character/token pairs. Balances vocabulary size against out-of-vocabulary (OOV) tokens and compression efficiency.
  • Temperature ($T$): Modulates logit sharpness $P_i = \exp(z_i / T) / \sum_j \exp(z_j / T)$. Low $T o 0$ approaches argmax greedy decoding; high $T > 1$ flattens distribution.
  • Top-P (Nucleus Sampling): Dynamically truncates vocabulary to the smallest set of tokens whose cumulative probability $\ge P$, adapting candidate pool size based on model confidence.

3. LeetCode #62 & #1143

  • Unique Paths: dp[i, j] = dp[i - 1, j] + dp[i, j - 1]. Space-optimizable to 1D array of size $\min(M, N)$. Closed-form combinatorics: $inom{M + N - 2}{M - 1}$.
  • Longest Common Subsequence: If text1[i] == text2[j], dp[i, j] = dp[i-1, j-1] + 1; else dp[i, j] = max(dp[i-1, j], dp[i, j-1]). Backtracking from $(M, N)$ recovers the LCS string.

10 Senior / Staff-Level Interview Questions with In-Depth Answers:
Q1 Why do Transformers scale quadratically O(N^2) with context length, and how does FlashAttention solve the GPU memory bottleneck?
▼

Answer:

Computing $QK^T$ requires calculating an attention score between every pair of tokens in a sequence of length $N$, producing an $N imes N$ matrix. In standard implementations:

  • $QK^T$ is written to High Bandwidth Memory (HBM).
  • Softmax reads and writes the $N imes N$ matrix back to HBM.
  • Matrix multiplication with $V$ reads from HBM again.

Memory bandwidth (not FLOPS) is the primary bottleneck. FlashAttention fuses the attention computation into GPU SRAM using tiling and online softmax scaling, eliminating intermediate $N imes N$ reads/writes to HBM and reducing memory from $\mathcal{O}(N^2)$ to $\mathcal{O}(N)$ while achieving 2x–4x wall-clock speedups.

Q2 What is the KV Cache in LLM inference, and why is its memory footprint a critical production concern?
▼

Answer:

During autoregressive generation, generating each new token only requires computing $Q$ for the single new token, but it must attend to all previous tokens\' $K$ and $V$ vectors. Without caching, all past tokens must be recomputed at every step ($\mathcal{O}(N^2)$ per generation).

The KV Cache stores the Key and Value tensors for all past tokens across all layers.

Memory Footprint:

$$ ext{Memory} = 2 imes 2 imes ext{layers} imes ext{heads} imes d_{ ext{head}} imes ext{context\_len} imes ext{batch\_size} imes ext{bytes\_per\_param}$$

For a 70B model with 4k context and batch size 16 in FP16, KV cache alone can exceed 40 GB of VRAM. Architectures like Grouped-Query Attention (GQA) share Key/Value heads across multiple Query heads to reduce KV cache size by 4x–8x.

Q3 Contrast Byte-Pair Encoding (BPE), WordPiece, and SentencePiece tokenization.
▼

Answer:

  • BPE (GPT, Llama): Bottom-up merge algorithm based on raw frequency counts of adjacent symbol pairs. Operates on bytes to avoid OOV tokens entirely.
  • WordPiece (BERT): Similar to BPE, but selects pair merges that maximize the likelihood of the training data according to a unigram language model rather than pure frequency.
  • SentencePiece (T5, Llama): Treats whitespace as a regular symbol (e.g. _), eliminating language-dependent pre-tokenizers and supporting multilingual scripts natively.
Q4 Explain the mathematical relationship between Temperature and Top-P (Nucleus) sampling.
▼

Answer:

  • Temperature ($T$) scales the raw logits $z_i / T$ before the softmax function. It changes the entropy of the probability distribution: low $T$ makes high logits dominate exponentially, whereas high $T$ makes probabilities more uniform.
  • Top-P (Nucleus) acts after softmax. It sorts tokens by probability and discards all tail tokens beyond the cumulative threshold $P$.

Interaction: Temperature reshapes the probability curve, which directly affects how many tokens are included in the Top-P cumulative cutoff. High temperature fattens the tail, causing Top-P to include more candidate tokens; low temperature causes Top-P to include fewer tokens.

Q5 How do Frequency and Presence penalties prevent degenerate LLM repetition?
▼

Answer:

  • Frequency Penalty: Proportional to the exact count of times a token has already appeared:

$$z_i^{\prime} = z_i - ( ext{count}_i imes lpha_{ ext{freq}})$$

Penalizes words increasingly the more often they are repeated.

  • Presence Penalty: A flat one-time penalty applied if the token has appeared at least once:

$$z_i^{\prime} = z_i - (\mathbb{I}( ext{count}_i > 0) imes lpha_{ ext{pres}})$$

Encourages the model to introduce new topics and avoid looping phrases without overly penalizing common grammatical words (like "the", "is").

Q6 What are Rotary Position Embeddings (RoPE) and why have they replaced Sinusoidal/Absolute Embeddings?
▼

Answer:

Absolute sinusoidal embeddings add a position-dependent vector to token embeddings before the first layer: $x_{pos} = x + PE_{pos}$. However, attention depends on relative distance between tokens ($m - n$), not absolute position.

RoPE rotates the Query and Key vectors in 2D complex coordinate subspaces by an angle proportional to position:

$$R_{\Theta, m} Q_m$$

The inner product $(R_m Q)^T (R_n K) = Q^T R_{n - m} K$ naturally encodes relative distance $(m - n)$. RoPE offers superior context length extrapolation and has become the universal standard across Llama, Mistral, and DeepSeek.

Q7 Why do we use Layer Normalization (RMSNorm) rather than Batch Normalization in Transformers?
▼

Answer:

  • BatchNorm normalizes across the batch dimension. It fails in NLP/LLMs because input sentence lengths vary dynamically within a batch, and during single-sample autoregressive inference (batch size 1), variance is zero.
  • LayerNorm / RMSNorm normalizes across the feature/embedding dimension for each individual token independently. It is invariant to batch size and sequence length. RMSNorm (Root Mean Square Normalization) further omits mean-centering, reducing computational overhead without loss of model quality.
Q8 What is the purpose of the Feed-Forward Network (FFN) layer in a Transformer block?
▼

Answer:

Self-Attention is purely an aggregation and routing mechanism: it mixes information across tokens but performs linear combinations. The Feed-Forward Network (FFN) consists of two linear transformations with a non-linear activation (GeLU or SwiGLU) in between:

$$ ext{FFN}(x) = \sigma(x W_1) W_2$$

Typically, the hidden dimension is expanded by 4x ($d_{ ext{ffn}} = 4 \cdot d_{ ext{model}}$). The FFN acts as a key-value associative memory where factual knowledge and linguistic patterns learned during pretraining are stored.

Q9 Explain how Unique Paths can be solved in O(1) space using Combinatorics.
▼

Answer:

In an $M imes N$ grid, any path from $(0, 0)$ to $(M - 1, N - 1)$ requires making exactly $(M - 1)$ downward steps and $(N - 1)$ rightward steps. The total number of steps is fixed:

$$T = (M - 1) + (N - 1) = M + N - 2$$

The problem reduces to choosing $(M - 1)$ down steps out of $T$ total steps:

$$inom{M + N - 2}{M - 1} =

rac{(M + N - 2)!}{(M - 1)! (N - 1)!}$$

This can be computed in $\mathcal{O}(\min(M, N))$ time and $\mathcal{O}(1)$ auxiliary space by multiplying sequentially and dividing iteratively to prevent 64-bit integer overflow.

Q10 How do you optimize Longest Common Subsequence to O(min(M, N)) auxiliary space?
▼

Answer:

In the 2D DP transition:

$$ ext{dp}[i, j] = egin{cases} ext{dp}[i-1, j-1] + 1 & ext{if } text1[i] = text2[j] \ \max( ext{dp}[i-1, j], ext{dp}[i, j-1]) & ext{otherwise} \end{cases}$$

Computing row $i$ only depends on the current row $i$ and the immediately preceding row $i - 1$.

  • We can maintain just two rows of length $N$: prev[N + 1] and curr[N + 1].
  • Furthermore, we can ensure $N \le M$ by swapping strings if $M < N$.
  • This reduces auxiliary space from $\mathcal{O}(M imes N)$ to $\mathcal{O}(\min(M, N))$.

Note: While space is optimized to $\mathcal{O}(\min(M, N))$ for calculating length, reconstructing the exact LCS string still requires the full 2D table or Hirschberg\'s divide-and-conquer algorithm.

namespace Day51.AiLlmFoundations;

using System;
using System.Collections.Generic;
using System.Linq;

public class TransformerAttentionEngine
{
    /// <summary>
    /// Computes Scaled Dot-Product Attention: Softmax(Q * K^T / sqrt(d_k)) * V
    /// Supports causal masking for autoregressive decoders.
    /// </summary>
    public static double[,] ScaledDotProductAttention(
        double[,] Q,
        double[,] K,
        double[,] V,
        bool isCausal = false)
    {
        int seqLenQ = Q.GetLength(0);
        int dK = Q.GetLength(1);
        int seqLenK = K.GetLength(0);
        int dV = V.GetLength(1);

        double scale = Math.Sqrt(dK);
        double[,] scores = new double[seqLenQ, seqLenK];

        // 1. Q * K^T / sqrt(d_k)
        for (int i = 0; i < seqLenQ; i++)
        {
            for (int j = 0; j < seqLenK; j++)
            {
                if (isCausal && j > i)
                {
                    scores[i, j] = -1e9; // Causal mask
                    continue;
                }

                double dot = 0;
                for (int d = 0; d < dK; d++)
                {
                    dot += Q[i, d] * K[j, d];
                }
                scores[i, j] = dot / scale;
            }
        }

        // 2. Softmax per row
        double[,] attentionWeights = new double[seqLenQ, seqLenK];
        for (int i = 0; i < seqLenQ; i++)
        {
            double maxScore = double.NegativeInfinity;
            for (int j = 0; j < seqLenK; j++)
            {
                if (scores[i, j] > maxScore) maxScore = scores[i, j];
            }

            double sumExp = 0;
            for (int j = 0; j < seqLenK; j++)
            {
                attentionWeights[i, j] = Math.Exp(scores[i, j] - maxScore);
                sumExp += attentionWeights[i, j];
            }

            for (int j = 0; j < seqLenK; j++)
            {
                attentionWeights[i, j] /= sumExp;
            }
        }

        // 3. AttentionWeights * V
        double[,] output = new double[seqLenQ, dV];
        for (int i = 0; i < seqLenQ; i++)
        {
            for (int v = 0; v < dV; v++)
            {
                double sum = 0;
                for (int j = 0; j < seqLenK; j++)
                {
                    sum += attentionWeights[i, j] * V[j, v];
                }
                output[i, v] = sum;
            }
        }

        return output;
    }

    /// <summary>
    /// Generates Sinusoidal Positional Encoding matrix of shape [seqLen, dModel].
    /// </summary>
    public static double[,] GeneratePositionalEncoding(int seqLen, int dModel)
    {
        double[,] pe = new double[seqLen, dModel];
        for (int pos = 0; pos < seqLen; pos++)
        {
            for (int i = 0; i < dModel; i += 2)
            {
                double denominator = Math.Pow(10000, (double)i / dModel);
                pe[pos, i] = Math.Sin(pos / denominator);
                if (i + 1 < dModel)
                {
                    pe[pos, i + 1] = Math.Cos(pos / denominator);
                }
            }
        }
        return pe;
    }
}

public class BytePairEncodingTokenizer
{
    private readonly Dictionary<string, int> _vocab = new();
    private readonly List<(string, string)> _merges = new();

    public void Train(string text, int numMerges)
    {
        var words = text.Split(' ', StringSplitOptions.RemoveEmptyEntries)
                        .Select(w => string.Join(' ', w.ToCharArray()) + " </w>")
                        .ToList();

        // Initialize base vocab
        int nextId = 0;
        foreach (var c in text.Distinct().Where(c => c != ' '))
        {
            if (!_vocab.ContainsKey(c.ToString())) _vocab[c.ToString()] = nextId++;
        }
        if (!_vocab.ContainsKey("</w>")) _vocab["</w>"] = nextId++;

        for (int m = 0; m < numMerges; m++)
        {
            var pairCounts = new Dictionary<(string, string), int>();

            foreach (var word in words)
            {
                var symbols = word.Split(' ');
                for (int i = 0; i < symbols.Length - 1; i++)
                {
                    var pair = (symbols[i], symbols[i + 1]);
                    pairCounts[pair] = pairCounts.GetValueOrDefault(pair) + 1;
                }
            }

            if (pairCounts.Count == 0) break;

            var bestPair = pairCounts.OrderByDescending(kvp => kvp.Value).First().Key;
            _merges.Add(bestPair);
            string mergedToken = bestPair.Item1 + bestPair.Item2;
            _vocab[mergedToken] = nextId++;

            // Replace in words
            string target = $"{bestPair.Item1} {bestPair.Item2}";
            for (int i = 0; i < words.Count; i++)
            {
                words[i] = words[i].Replace(target, mergedToken);
            }
        }
    }

    public List<string> Tokenize(string text)
    {
        var tokens = new List<string>();
        var words = text.Split(' ', StringSplitOptions.RemoveEmptyEntries);

        foreach (var w in words)
        {
            string current = string.Join(' ', w.ToCharArray()) + " </w>";
            foreach (var (p1, p2) in _merges)
            {
                current = current.Replace($"{p1} {p2}", $"{p1}{p2}");
            }
            tokens.AddRange(current.Split(' '));
        }

        return tokens;
    }

    public int VocabSize => _vocab.Count;
}

public class LlmSamplingEngine
{
    /// <summary>
    /// Applies Temperature scaling to raw logits.
    /// </summary>
    public static double[] ApplyTemperature(double[] logits, double temperature)
    {
        if (temperature <= 0.001) temperature = 0.001; // Guard against divide-by-zero
        double[] scaled = new double[logits.Length];
        for (int i = 0; i < logits.Length; i++)
        {
            scaled[i] = logits[i] / temperature;
        }
        return Softmax(scaled);
    }

    /// <summary>
    /// Applies Top-P (Nucleus) filtering: zeroes out probabilities outside cumulative threshold p.
    /// </summary>
    public static double[] ApplyTopP(double[] probabilities, double p)
    {
        int n = probabilities.Length;
        var indexed = probabilities.Select((prob, idx) => (prob, idx))
                                   .OrderByDescending(x => x.prob)
                                   .ToList();

        double cumulative = 0;
        var filtered = new double[n];
        double filteredSum = 0;

        foreach (var (prob, idx) in indexed)
        {
            filtered[idx] = prob;
            filteredSum += prob;
            cumulative += prob;
            if (cumulative >= p) break;
        }

        // Renormalize
        for (int i = 0; i < n; i++)
        {
            filtered[i] /= filteredSum;
        }

        return filtered;
    }

    /// <summary>
    /// Applies Frequency & Presence repetition penalty to logits.
    /// </summary>
    public static double[] ApplyRepetitionPenalty(
        double[] logits,
        Dictionary<int, int> tokenFrequency,
        double frequencyPenalty,
        double presencePenalty)
    {
        double[] penalized = (double[])logits.Clone();
        foreach (var (tokenId, count) in tokenFrequency)
        {
            if (tokenId >= 0 && tokenId < penalized.Length)
            {
                penalized[tokenId] -= (count * frequencyPenalty + (count > 0 ? presencePenalty : 0));
            }
        }
        return penalized;
    }

    private static double[] Softmax(double[] values)
    {
        double max = values.Max();
        double sum = values.Sum(v => Math.Exp(v - max));
        return values.Select(v => Math.Exp(v - max) / sum).ToArray();
    }
}

namespace Day51.AiLlmFoundations;

using System;
using System.Text;

public class UniquePathsAndLcsSolver
{
    /// <summary>
    /// LeetCode #62: Unique Paths via 2D Dynamic Programming grid.
    /// </summary>
    public static int UniquePaths2D(int m, int n)
    {
        if (m <= 0 || n <= 0) return 0;
        int[,] dp = new int[m, n];

        for (int i = 0; i < m; i++) dp[i, 0] = 1;
        for (int j = 0; j < n; j++) dp[0, j] = 1;

        for (int i = 1; i < m; i++)
        {
            for (int j = 1; j < n; j++)
            {
                dp[i, j] = dp[i - 1, j] + dp[i, j - 1];
            }
        }

        return dp[m - 1, n - 1];
    }

    /// <summary>
    /// LeetCode #62: Unique Paths via 1D rolling array O(min(m, n)) space.
    /// </summary>
    public static int UniquePaths1D(int m, int n)
    {
        if (m <= 0 || n <= 0) return 0;
        if (m < n) (m, n) = (n, m); // Ensure n is the smaller dimension

        int[] dp = new int[n];
        Array.Fill(dp, 1);

        for (int i = 1; i < m; i++)
        {
            for (int j = 1; j < n; j++)
            {
                dp[j] += dp[j - 1];
            }
        }

        return dp[n - 1];
    }

    /// <summary>
    /// LeetCode #62: Combinatorics formula C(m+n-2, m-1).
    /// </summary>
    public static long UniquePathsCombinatorics(int m, int n)
    {
        if (m <= 0 || n <= 0) return 0;
        int totalMoves = m + n - 2;
        int k = Math.Min(m - 1, n - 1);

        long result = 1;
        for (int i = 1; i <= k; i++)
        {
            result = result * (totalMoves - i + 1) / i;
        }

        return result;
    }

    /// <summary>
    /// LeetCode #1143: Longest Common Subsequence length O(M * N).
    /// </summary>
    public static int LongestCommonSubsequenceLength(string text1, string text2)
    {
        if (string.IsNullOrEmpty(text1) || string.IsNullOrEmpty(text2)) return 0;

        int m = text1.Length;
        int n = text2.Length;
        int[,] dp = new int[m + 1, n + 1];

        for (int i = 1; i <= m; i++)
        {
            for (int j = 1; j <= n; j++)
            {
                if (text1[i - 1] == text2[j - 1])
                {
                    dp[i, j] = dp[i - 1, j - 1] + 1;
                }
                else
                {
                    dp[i, j] = Math.Max(dp[i - 1, j], dp[i, j - 1]);
                }
            }
        }

        return dp[m, n];
    }

    /// <summary>
    /// Reconstructs the actual LCS string via backtracking through the DP table.
    /// </summary>
    public static string GetLcsString(string text1, string text2)
    {
        if (string.IsNullOrEmpty(text1) || string.IsNullOrEmpty(text2)) return string.Empty;

        int m = text1.Length;
        int n = text2.Length;
        int[,] dp = new int[m + 1, n + 1];

        for (int i = 1; i <= m; i++)
        {
            for (int j = 1; j <= n; j++)
            {
                if (text1[i - 1] == text2[j - 1])
                {
                    dp[i, j] = dp[i - 1, j - 1] + 1;
                }
                else
                {
                    dp[i, j] = Math.Max(dp[i - 1, j], dp[i, j - 1]);
                }
            }
        }

        var sb = new StringBuilder();
        int r = m, c = n;
        while (r > 0 && c > 0)
        {
            if (text1[r - 1] == text2[c - 1])
            {
                sb.Append(text1[r - 1]);
                r--;
                c--;
            }
            else if (dp[r - 1, c] >= dp[r, c - 1])
            {
                r--;
            }
            else
            {
                c--;
            }
        }

        char[] arr = sb.ToString().ToCharArray();
        Array.Reverse(arr);
        return new string(arr);
    }
}

📝 Part 1: Deep-Dive Architectural & Engineering Notes

Technical Notes: Transformer Architecture & LLM Foundations

1. Scaled Dot-Product & Causal Attention Mechanics

  • Scale Factor $\sqrt{d_k}$: For large projection dimensions $d_k$, the dot product $QK^T$ grows large in magnitude, pushing the softmax function into regions with near-zero gradients (vanishing gradient problem). Dividing by $\sqrt{d_k}$ stabilizes variance to 1.0.
  • Causal Masking: In decoder-only architectures (GPT, Llama, Mistral), token $i$ must not attend to token $j > i$. Applying an upper-triangular mask of $-\infty$ ensures that $\exp(-\infty) = 0$ after softmax, preserving strict autoregression.

2. Tokenization & Sampling Mechanics

  • Byte-Pair Encoding (BPE): Subword tokenization iteratively merges the most frequent adjacent character/token pairs. Balances vocabulary size against out-of-vocabulary (OOV) tokens and compression efficiency.
  • Temperature ($T$): Modulates logit sharpness $P_i = \exp(z_i / T) / \sum_j \exp(z_j / T)$. Low $T o 0$ approaches argmax greedy decoding; high $T > 1$ flattens distribution.
  • Top-P (Nucleus Sampling): Dynamically truncates vocabulary to the smallest set of tokens whose cumulative probability $\ge P$, adapting candidate pool size based on model confidence.

3. LeetCode #62 & #1143

  • Unique Paths: dp[i, j] = dp[i - 1, j] + dp[i, j - 1]. Space-optimizable to 1D array of size $\min(M, N)$. Closed-form combinatorics: $inom{M + N - 2}{M - 1}$.
  • Longest Common Subsequence: If text1[i] == text2[j], dp[i, j] = dp[i-1, j-1] + 1; else dp[i, j] = max(dp[i-1, j], dp[i, j-1]). Backtracking from $(M, N)$ recovers the LCS string.

💡 Part 3: Senior & Staff-Level Interview Scenarios (10 Questions)

Q1 Why do Transformers scale quadratically O(N^2) with context length, and how does FlashAttention solve the GPU memory bottleneck?
▼

Answer:

Computing $QK^T$ requires calculating an attention score between every pair of tokens in a sequence of length $N$, producing an $N imes N$ matrix. In standard implementations:

  • $QK^T$ is written to High Bandwidth Memory (HBM).
  • Softmax reads and writes the $N imes N$ matrix back to HBM.
  • Matrix multiplication with $V$ reads from HBM again.

Memory bandwidth (not FLOPS) is the primary bottleneck. FlashAttention fuses the attention computation into GPU SRAM using tiling and online softmax scaling, eliminating intermediate $N imes N$ reads/writes to HBM and reducing memory from $\mathcal{O}(N^2)$ to $\mathcal{O}(N)$ while achieving 2x–4x wall-clock speedups.

Q2 What is the KV Cache in LLM inference, and why is its memory footprint a critical production concern?
▼

Answer:

During autoregressive generation, generating each new token only requires computing $Q$ for the single new token, but it must attend to all previous tokens\' $K$ and $V$ vectors. Without caching, all past tokens must be recomputed at every step ($\mathcal{O}(N^2)$ per generation).

The KV Cache stores the Key and Value tensors for all past tokens across all layers.

Memory Footprint:

$$ ext{Memory} = 2 imes 2 imes ext{layers} imes ext{heads} imes d_{ ext{head}} imes ext{context\_len} imes ext{batch\_size} imes ext{bytes\_per\_param}$$

For a 70B model with 4k context and batch size 16 in FP16, KV cache alone can exceed 40 GB of VRAM. Architectures like Grouped-Query Attention (GQA) share Key/Value heads across multiple Query heads to reduce KV cache size by 4x–8x.

Q3 Contrast Byte-Pair Encoding (BPE), WordPiece, and SentencePiece tokenization.
▼

Answer:

  • BPE (GPT, Llama): Bottom-up merge algorithm based on raw frequency counts of adjacent symbol pairs. Operates on bytes to avoid OOV tokens entirely.
  • WordPiece (BERT): Similar to BPE, but selects pair merges that maximize the likelihood of the training data according to a unigram language model rather than pure frequency.
  • SentencePiece (T5, Llama): Treats whitespace as a regular symbol (e.g. _), eliminating language-dependent pre-tokenizers and supporting multilingual scripts natively.
Q4 Explain the mathematical relationship between Temperature and Top-P (Nucleus) sampling.
▼

Answer:

  • Temperature ($T$) scales the raw logits $z_i / T$ before the softmax function. It changes the entropy of the probability distribution: low $T$ makes high logits dominate exponentially, whereas high $T$ makes probabilities more uniform.
  • Top-P (Nucleus) acts after softmax. It sorts tokens by probability and discards all tail tokens beyond the cumulative threshold $P$.

Interaction: Temperature reshapes the probability curve, which directly affects how many tokens are included in the Top-P cumulative cutoff. High temperature fattens the tail, causing Top-P to include more candidate tokens; low temperature causes Top-P to include fewer tokens.

Q5 How do Frequency and Presence penalties prevent degenerate LLM repetition?
▼

Answer:

  • Frequency Penalty: Proportional to the exact count of times a token has already appeared:

$$z_i^{\prime} = z_i - ( ext{count}_i imes lpha_{ ext{freq}})$$

Penalizes words increasingly the more often they are repeated.

  • Presence Penalty: A flat one-time penalty applied if the token has appeared at least once:

$$z_i^{\prime} = z_i - (\mathbb{I}( ext{count}_i > 0) imes lpha_{ ext{pres}})$$

Encourages the model to introduce new topics and avoid looping phrases without overly penalizing common grammatical words (like "the", "is").

Q6 What are Rotary Position Embeddings (RoPE) and why have they replaced Sinusoidal/Absolute Embeddings?
▼

Answer:

Absolute sinusoidal embeddings add a position-dependent vector to token embeddings before the first layer: $x_{pos} = x + PE_{pos}$. However, attention depends on relative distance between tokens ($m - n$), not absolute position.

RoPE rotates the Query and Key vectors in 2D complex coordinate subspaces by an angle proportional to position:

$$R_{\Theta, m} Q_m$$

The inner product $(R_m Q)^T (R_n K) = Q^T R_{n - m} K$ naturally encodes relative distance $(m - n)$. RoPE offers superior context length extrapolation and has become the universal standard across Llama, Mistral, and DeepSeek.

Q7 Why do we use Layer Normalization (RMSNorm) rather than Batch Normalization in Transformers?
▼

Answer:

  • BatchNorm normalizes across the batch dimension. It fails in NLP/LLMs because input sentence lengths vary dynamically within a batch, and during single-sample autoregressive inference (batch size 1), variance is zero.
  • LayerNorm / RMSNorm normalizes across the feature/embedding dimension for each individual token independently. It is invariant to batch size and sequence length. RMSNorm (Root Mean Square Normalization) further omits mean-centering, reducing computational overhead without loss of model quality.
Q8 What is the purpose of the Feed-Forward Network (FFN) layer in a Transformer block?
▼

Answer:

Self-Attention is purely an aggregation and routing mechanism: it mixes information across tokens but performs linear combinations. The Feed-Forward Network (FFN) consists of two linear transformations with a non-linear activation (GeLU or SwiGLU) in between:

$$ ext{FFN}(x) = \sigma(x W_1) W_2$$

Typically, the hidden dimension is expanded by 4x ($d_{ ext{ffn}} = 4 \cdot d_{ ext{model}}$). The FFN acts as a key-value associative memory where factual knowledge and linguistic patterns learned during pretraining are stored.

Q9 Explain how Unique Paths can be solved in O(1) space using Combinatorics.
▼

Answer:

In an $M imes N$ grid, any path from $(0, 0)$ to $(M - 1, N - 1)$ requires making exactly $(M - 1)$ downward steps and $(N - 1)$ rightward steps. The total number of steps is fixed:

$$T = (M - 1) + (N - 1) = M + N - 2$$

The problem reduces to choosing $(M - 1)$ down steps out of $T$ total steps:

$$inom{M + N - 2}{M - 1} =

rac{(M + N - 2)!}{(M - 1)! (N - 1)!}$$

This can be computed in $\mathcal{O}(\min(M, N))$ time and $\mathcal{O}(1)$ auxiliary space by multiplying sequentially and dividing iteratively to prevent 64-bit integer overflow.

Q10 How do you optimize Longest Common Subsequence to O(min(M, N)) auxiliary space?
▼

Answer:

In the 2D DP transition:

$$ ext{dp}[i, j] = egin{cases} ext{dp}[i-1, j-1] + 1 & ext{if } text1[i] = text2[j] \ \max( ext{dp}[i-1, j], ext{dp}[i, j-1]) & ext{otherwise} \end{cases}$$

Computing row $i$ only depends on the current row $i$ and the immediately preceding row $i - 1$.

  • We can maintain just two rows of length $N$: prev[N + 1] and curr[N + 1].
  • Furthermore, we can ensure $N \le M$ by swapping strings if $M < N$.
  • This reduces auxiliary space from $\mathcal{O}(M imes N)$ to $\mathcal{O}(\min(M, N))$.

Note: While space is optimized to $\mathcal{O}(\min(M, N))$ for calculating length, reconstructing the exact LCS string still requires the full 2D table or Hirschberg\'s divide-and-conquer algorithm.

namespace Day51.AiLlmFoundations;

using System;
using System.Collections.Generic;
using System.Linq;

public class TransformerAttentionEngine
{
    /// <summary>
    /// Computes Scaled Dot-Product Attention: Softmax(Q * K^T / sqrt(d_k)) * V
    /// Supports causal masking for autoregressive decoders.
    /// </summary>
    public static double[,] ScaledDotProductAttention(
        double[,] Q,
        double[,] K,
        double[,] V,
        bool isCausal = false)
    {
        int seqLenQ = Q.GetLength(0);
        int dK = Q.GetLength(1);
        int seqLenK = K.GetLength(0);
        int dV = V.GetLength(1);

        double scale = Math.Sqrt(dK);
        double[,] scores = new double[seqLenQ, seqLenK];

        // 1. Q * K^T / sqrt(d_k)
        for (int i = 0; i < seqLenQ; i++)
        {
            for (int j = 0; j < seqLenK; j++)
            {
                if (isCausal && j > i)
                {
                    scores[i, j] = -1e9; // Causal mask
                    continue;
                }

                double dot = 0;
                for (int d = 0; d < dK; d++)
                {
                    dot += Q[i, d] * K[j, d];
                }
                scores[i, j] = dot / scale;
            }
        }

        // 2. Softmax per row
        double[,] attentionWeights = new double[seqLenQ, seqLenK];
        for (int i = 0; i < seqLenQ; i++)
        {
            double maxScore = double.NegativeInfinity;
            for (int j = 0; j < seqLenK; j++)
            {
                if (scores[i, j] > maxScore) maxScore = scores[i, j];
            }

            double sumExp = 0;
            for (int j = 0; j < seqLenK; j++)
            {
                attentionWeights[i, j] = Math.Exp(scores[i, j] - maxScore);
                sumExp += attentionWeights[i, j];
            }

            for (int j = 0; j < seqLenK; j++)
            {
                attentionWeights[i, j] /= sumExp;
            }
        }

        // 3. AttentionWeights * V
        double[,] output = new double[seqLenQ, dV];
        for (int i = 0; i < seqLenQ; i++)
        {
            for (int v = 0; v < dV; v++)
            {
                double sum = 0;
                for (int j = 0; j < seqLenK; j++)
                {
                    sum += attentionWeights[i, j] * V[j, v];
                }
                output[i, v] = sum;
            }
        }

        return output;
    }

    /// <summary>
    /// Generates Sinusoidal Positional Encoding matrix of shape [seqLen, dModel].
    /// </summary>
    public static double[,] GeneratePositionalEncoding(int seqLen, int dModel)
    {
        double[,] pe = new double[seqLen, dModel];
        for (int pos = 0; pos < seqLen; pos++)
        {
            for (int i = 0; i < dModel; i += 2)
            {
                double denominator = Math.Pow(10000, (double)i / dModel);
                pe[pos, i] = Math.Sin(pos / denominator);
                if (i + 1 < dModel)
                {
                    pe[pos, i + 1] = Math.Cos(pos / denominator);
                }
            }
        }
        return pe;
    }
}

public class BytePairEncodingTokenizer
{
    private readonly Dictionary<string, int> _vocab = new();
    private readonly List<(string, string)> _merges = new();

    public void Train(string text, int numMerges)
    {
        var words = text.Split(' ', StringSplitOptions.RemoveEmptyEntries)
                        .Select(w => string.Join(' ', w.ToCharArray()) + " </w>")
                        .ToList();

        // Initialize base vocab
        int nextId = 0;
        foreach (var c in text.Distinct().Where(c => c != ' '))
        {
            if (!_vocab.ContainsKey(c.ToString())) _vocab[c.ToString()] = nextId++;
        }
        if (!_vocab.ContainsKey("</w>")) _vocab["</w>"] = nextId++;

        for (int m = 0; m < numMerges; m++)
        {
            var pairCounts = new Dictionary<(string, string), int>();

            foreach (var word in words)
            {
                var symbols = word.Split(' ');
                for (int i = 0; i < symbols.Length - 1; i++)
                {
                    var pair = (symbols[i], symbols[i + 1]);
                    pairCounts[pair] = pairCounts.GetValueOrDefault(pair) + 1;
                }
            }

            if (pairCounts.Count == 0) break;

            var bestPair = pairCounts.OrderByDescending(kvp => kvp.Value).First().Key;
            _merges.Add(bestPair);
            string mergedToken = bestPair.Item1 + bestPair.Item2;
            _vocab[mergedToken] = nextId++;

            // Replace in words
            string target = $"{bestPair.Item1} {bestPair.Item2}";
            for (int i = 0; i < words.Count; i++)
            {
                words[i] = words[i].Replace(target, mergedToken);
            }
        }
    }

    public List<string> Tokenize(string text)
    {
        var tokens = new List<string>();
        var words = text.Split(' ', StringSplitOptions.RemoveEmptyEntries);

        foreach (var w in words)
        {
            string current = string.Join(' ', w.ToCharArray()) + " </w>";
            foreach (var (p1, p2) in _merges)
            {
                current = current.Replace($"{p1} {p2}", $"{p1}{p2}");
            }
            tokens.AddRange(current.Split(' '));
        }

        return tokens;
    }

    public int VocabSize => _vocab.Count;
}

public class LlmSamplingEngine
{
    /// <summary>
    /// Applies Temperature scaling to raw logits.
    /// </summary>
    public static double[] ApplyTemperature(double[] logits, double temperature)
    {
        if (temperature <= 0.001) temperature = 0.001; // Guard against divide-by-zero
        double[] scaled = new double[logits.Length];
        for (int i = 0; i < logits.Length; i++)
        {
            scaled[i] = logits[i] / temperature;
        }
        return Softmax(scaled);
    }

    /// <summary>
    /// Applies Top-P (Nucleus) filtering: zeroes out probabilities outside cumulative threshold p.
    /// </summary>
    public static double[] ApplyTopP(double[] probabilities, double p)
    {
        int n = probabilities.Length;
        var indexed = probabilities.Select((prob, idx) => (prob, idx))
                                   .OrderByDescending(x => x.prob)
                                   .ToList();

        double cumulative = 0;
        var filtered = new double[n];
        double filteredSum = 0;

        foreach (var (prob, idx) in indexed)
        {
            filtered[idx] = prob;
            filteredSum += prob;
            cumulative += prob;
            if (cumulative >= p) break;
        }

        // Renormalize
        for (int i = 0; i < n; i++)
        {
            filtered[i] /= filteredSum;
        }

        return filtered;
    }

    /// <summary>
    /// Applies Frequency & Presence repetition penalty to logits.
    /// </summary>
    public static double[] ApplyRepetitionPenalty(
        double[] logits,
        Dictionary<int, int> tokenFrequency,
        double frequencyPenalty,
        double presencePenalty)
    {
        double[] penalized = (double[])logits.Clone();
        foreach (var (tokenId, count) in tokenFrequency)
        {
            if (tokenId >= 0 && tokenId < penalized.Length)
            {
                penalized[tokenId] -= (count * frequencyPenalty + (count > 0 ? presencePenalty : 0));
            }
        }
        return penalized;
    }

    private static double[] Softmax(double[] values)
    {
        double max = values.Max();
        double sum = values.Sum(v => Math.Exp(v - max));
        return values.Select(v => Math.Exp(v - max) / sum).ToArray();
    }
}

namespace Day51.AiLlmFoundations;

using System;
using System.Text;

public class UniquePathsAndLcsSolver
{
    /// <summary>
    /// LeetCode #62: Unique Paths via 2D Dynamic Programming grid.
    /// </summary>
    public static int UniquePaths2D(int m, int n)
    {
        if (m <= 0 || n <= 0) return 0;
        int[,] dp = new int[m, n];

        for (int i = 0; i < m; i++) dp[i, 0] = 1;
        for (int j = 0; j < n; j++) dp[0, j] = 1;

        for (int i = 1; i < m; i++)
        {
            for (int j = 1; j < n; j++)
            {
                dp[i, j] = dp[i - 1, j] + dp[i, j - 1];
            }
        }

        return dp[m - 1, n - 1];
    }

    /// <summary>
    /// LeetCode #62: Unique Paths via 1D rolling array O(min(m, n)) space.
    /// </summary>
    public static int UniquePaths1D(int m, int n)
    {
        if (m <= 0 || n <= 0) return 0;
        if (m < n) (m, n) = (n, m); // Ensure n is the smaller dimension

        int[] dp = new int[n];
        Array.Fill(dp, 1);

        for (int i = 1; i < m; i++)
        {
            for (int j = 1; j < n; j++)
            {
                dp[j] += dp[j - 1];
            }
        }

        return dp[n - 1];
    }

    /// <summary>
    /// LeetCode #62: Combinatorics formula C(m+n-2, m-1).
    /// </summary>
    public static long UniquePathsCombinatorics(int m, int n)
    {
        if (m <= 0 || n <= 0) return 0;
        int totalMoves = m + n - 2;
        int k = Math.Min(m - 1, n - 1);

        long result = 1;
        for (int i = 1; i <= k; i++)
        {
            result = result * (totalMoves - i + 1) / i;
        }

        return result;
    }

    /// <summary>
    /// LeetCode #1143: Longest Common Subsequence length O(M * N).
    /// </summary>
    public static int LongestCommonSubsequenceLength(string text1, string text2)
    {
        if (string.IsNullOrEmpty(text1) || string.IsNullOrEmpty(text2)) return 0;

        int m = text1.Length;
        int n = text2.Length;
        int[,] dp = new int[m + 1, n + 1];

        for (int i = 1; i <= m; i++)
        {
            for (int j = 1; j <= n; j++)
            {
                if (text1[i - 1] == text2[j - 1])
                {
                    dp[i, j] = dp[i - 1, j - 1] + 1;
                }
                else
                {
                    dp[i, j] = Math.Max(dp[i - 1, j], dp[i, j - 1]);
                }
            }
        }

        return dp[m, n];
    }

    /// <summary>
    /// Reconstructs the actual LCS string via backtracking through the DP table.
    /// </summary>
    public static string GetLcsString(string text1, string text2)
    {
        if (string.IsNullOrEmpty(text1) || string.IsNullOrEmpty(text2)) return string.Empty;

        int m = text1.Length;
        int n = text2.Length;
        int[,] dp = new int[m + 1, n + 1];

        for (int i = 1; i <= m; i++)
        {
            for (int j = 1; j <= n; j++)
            {
                if (text1[i - 1] == text2[j - 1])
                {
                    dp[i, j] = dp[i - 1, j - 1] + 1;
                }
                else
                {
                    dp[i, j] = Math.Max(dp[i - 1, j], dp[i, j - 1]);
                }
            }
        }

        var sb = new StringBuilder();
        int r = m, c = n;
        while (r > 0 && c > 0)
        {
            if (text1[r - 1] == text2[c - 1])
            {
                sb.Append(text1[r - 1]);
                r--;
                c--;
            }
            else if (dp[r - 1, c] >= dp[r, c - 1])
            {
                r--;
            }
            else
            {
                c--;
            }
        }

        char[] arr = sb.ToString().ToCharArray();
        Array.Reverse(arr);
        return new string(arr);
    }
}

        Assert.True(filtered[0] > 0);

    [Fact]
    public void Test7_LlmSampling_RepetitionPenaltyDecreasesLogits()
    {
        double[] logits = { 5.0, 5.0, 5.0 };
        var freq = new Dictionary<int, int> { [0] = 2, [1] = 1 };

        double[] penalized = LlmSamplingEngine.ApplyRepetitionPenalty(
            logits, freq, frequencyPenalty: 0.5, presencePenalty: 0.2);

        // Token 0 penalized: 5 - (2*0.5 + 0.2) = 3.8
        Assert.Equal(3.8, Math.Round(penalized[0], 2));
        // Token 1 penalized: 5 - (1*0.5 + 0.2) = 4.3
        Assert.Equal(4.3, Math.Round(penalized[1], 2));
        // Token 2 untouched: 5.0
        Assert.Equal(5.0, penalized[2]);
    }
