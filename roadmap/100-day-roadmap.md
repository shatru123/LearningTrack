# 100-Day .NET + AI Engineering Roadmap

## Overview
This repository (`LearningTrack`) contains the hands-on engineering implementations, architectural labs, DSA solutions, benchmarks, and technical documentation for the 100-Day .NET + AI Engineering journey.

The curriculum schedule, daily tasks, and progress tracking are managed authoritatively by **LearningOS** (`https://learning-ttf6.onrender.com/`).

---

## Phase Breakdown

### Phase 1: High-Performance .NET Core & Systems Engineering (Days 1–25)
- **Day 01–08**: Recovery Sprint (Memory, Span, Ref Structs, Async/Await State Machine, Garbage Collection, Middleware/Kestrel, Dependency Injection Lifetimes, SQL B-Tree Indexes) - **Completed**
- **Day 09+**: Continues according to the authoritative LearningOS curriculum.

### Phase 2: Microservices, Distributed Systems & Observability (Days 26–50)
- Advanced messaging, event-driven architectures, distributed tracing, OpenTelemetry, resilience (Polly), caching patterns.

### Phase 3: Cloud Native, Docker, Kubernetes & Security (Days 51–75)
- Containerization, orchestration, service mesh, OAuth2/OIDC security, API gateways.

### Phase 4: Applied AI Engineering with .NET (Days 76–100)
- Semantic Kernel, LLM orchestrations, RAG pipelines, vector databases (pgvector), embeddings, AI agent architectures.
